# 삼국지14 CE 통합패치

삼국지14 CE 한국어판(2026-11-05 공식 업데이트판) 전용 통합패치입니다.

> **고쳐도 버그가 계속 나와서 "턴 종료 자동 논공"을 통합패치에서 뺐습니다.**
>
> - **논공은 게임의 논공 화면에서 직접** 해 주세요.

> - **그대로인 것**: 턴 종료 자동 포상 · 명승 자동 투자 · 자동인사(자동 탐색) · 13번 논공 개성 가챠
> - 설치기 **[업데이트]** 후 뜨는 **[갱신]** 을 누르면 게임 폴더의 옛 자동 논공 파일도 지워집니다.

## 처음 받는 분 (한 번만)
1. 위 초록색 **Code** 버튼 → **Download ZIP** 을 눌러 받습니다(약 500MB).
2. 받은 ZIP 을 아무 새 폴더에 풉니다. (Program Files·OneDrive 폴더는 피해 주세요)
3. 풀린 폴더의 **처음_설치.cmd** 를 더블클릭합니다.
   - 알아서 `통합패치` 폴더를 만들고 설치기를 엽니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
4. 설치기에서 원하는 번호를 고르고 **[선택 설치]** 를 누르면 끝입니다.

## 그다음부터
설치기를 켜면 새 판이 있는지 알려 줍니다. **[업데이트]** 버튼만 누르면 새 판을 받아 같은 폴더에 덮어씁니다.
여기서 따로 받을 것은 없습니다.

## 바뀐 내용
설치기의 **'업데이트' 탭**에서 판마다 바뀐 내용을 볼 수 있습니다. 판마다 종류가 붙어 있습니다.

| 표시 | 뜻 | 받을 사람 |
|---|---|---|
| **【중요】** | 기능이 빠지거나 동작이 크게 바뀜 | 모두 받기 권장 |
| **[새 기능]** | 새 번호·새 기능 추가 | 원하는 분만 |
| **[오류 수정]** | 특정 번호의 오류만 고침 | 그 번호를 쓰면서 그 증상이 있는 분만 (문제없이 쓰면 안 받아도 됨) |

판은 앞 판의 수정을 모두 포함합니다. 오류 수정판을 건너뛰어도 나중에 새 판을 받으면 그동안 고친 것도 함께 들어옵니다.
R43.38 설치기부터는 [업데이트] 버튼 색이 종류에 따라 바뀌고, 내가 깐 번호와 관련 없는 오류 수정판이면 "안 받아도 됨"으로 나옵니다.
