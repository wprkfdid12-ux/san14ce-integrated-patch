# 삼국지14 CE 통합패치

삼국지14 CE 한국어판(2026-11-05 공식 업데이트판) 전용 통합패치입니다.

## 처음 받는 분 (한 번만)
1. 위 초록색 **Code** 버튼 → **Download ZIP** 을 눌러 받습니다(약 500MB).
2. 받은 ZIP 을 아무 새 폴더에 풉니다. (Program Files·OneDrive 폴더는 피해 주세요)
3. 풀린 폴더의 **처음_설치.cmd** 를 더블클릭합니다.
   - 알아서 `통합패치` 폴더를 만들고 설치기를 엽니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
4. 설치기에서 원하는 번호를 고르고 **[선택 설치]** 를 누르면 끝입니다.

## 그다음부터
설치기를 켜면 새 판이 있는지 알려 줍니다. **[업데이트]** 버튼만 누르면 새 판을 받아 같은 폴더에 덮어씁니다.
여기서 따로 받을 것은 없습니다.

## 바뀐 내용
설치기의 **'업데이트' 탭**에서 판마다 바뀐 내용을 볼 수 있습니다.

## 소스
`source/` 폴더의 `통합패치_소스_R43.xx_1of1.zip` 이 통합패치 소스입니다. (설치·업데이트에는 필요 없습니다)
