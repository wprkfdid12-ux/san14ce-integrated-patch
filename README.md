# 삼국지14 CE 통합패치

삼국지14 CE 한국어판(2026-11-05 공식 업데이트판) 전용 통합패치입니다.

## 이미 통합패치 R43.28 이상을 쓰는 분
설치기의 **[업데이트]** 버튼을 누르면 새 판을 받아 옆에 새 폴더로 만들고, 지금 깔린 항목 그대로 갱신합니다. 여기서 따로 받을 것은 없습니다.

## 처음 받는 분
1. 위 초록색 **Code** 버튼 → **Download ZIP** 으로 이 저장소를 통째로 받습니다(약 500MB).
2. 받은 ZIP 을 풀고, `updates/base` 폴더의 ZIP 8개와 `updates/R43.28` 폴더의 ZIP 1개를 **모두 같은 새 폴더**에 풉니다(겹치는 파일은 덮어쓰기).
3. 그 폴더의 `설치.cmd` 를 실행합니다.

## 판 목록
`updates/index.json` 에 판마다 바뀐 내용이 있습니다(설치기의 '업데이트' 탭에도 같은 내용이 보입니다).
