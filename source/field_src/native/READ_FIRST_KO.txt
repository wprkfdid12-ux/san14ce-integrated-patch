FieldLeader3D R24 — 조형 변경 연동·통합 패치 호환 수정판

사용 방법
1. 삼국지14와 열려 있는 기존 FieldLeader3D 설치 창을 완전히 종료합니다.
2. 이 ZIP의 압축을 풀고 FieldLeader3D_Setup.exe를 실행합니다.
3. ‘설치 / 업데이트’를 한 번 누릅니다. 기존 R23/R23.1을 먼저 제거할 필요는 없습니다.
4. 설치 창을 닫고 평소처럼 게임을 실행합니다.
게임 위치를 못 찾을 때만 ‘게임 찾기’에서 SAN14CE_KO.exe를 선택하세요.

이번 수정
- 12번 ‘고유무장 등록·모델 ID 확장’에서 저장한 조형 선택을 필드에도 반영합니다.
- 원본 조형 번호 0~24 전체를 대상으로 합니다. 일반·고유 조형을 모두 포함합니다.
- 확장 번호 25~125는 12번의 사용 가능 목록과 연결된 자료가 있는 번호만 반영합니다.
  확장 조형 자료를 새로 제공하거나, 없는 조형을 만드는 패치는 아닙니다.
- 조형 등록을 바꾸거나 해제하면 필드에서도 자동으로 다시 읽습니다.
  변경 감지와 불러오기에 몇 초가 걸릴 수 있으며, 새 조형이 준비될 때까지 현재 조형을 유지합니다.
- 일반 조형의 색상은 12번의 원본 색상 처리 규칙을 따릅니다.
  말·무기와 말 색상은 게임이 현재 선택한 외형을 이어받습니다.
- 12번을 껐는데도 통합 패치의 부대정보 정리 기능 때문에 적용이 막히던 문제를 수정했습니다.
  통합 패치와 FieldLeader3D의 정리 기능을 모두 실행합니다.
- 기존 설치본 위에서 업데이트할 수 있습니다. 다른 패치의 파일은 덮어쓰거나 삭제하지 않습니다.
- 적용 실패 시 ‘확인’을 누르면 이번 실패 기록 ZIP이 선택된 폴더가 열립니다.
  파일을 찾거나 여러 로그를 모을 필요 없이, 선택된 ZIP 하나를 보내 주세요.

기존 기능
이동·통상공격·전법·막기·피격, 말 색상, 부대정보 정리, 포로 판정에 따른 낙마,
먼지·반구형 효과 정리와 기존 성능 개선을 유지합니다.
공성병기는 원본 조형·동작·이펙트·소리를 유지하며 부대정보 정리만 적용합니다.
그룹별 말 크기 조절은 이번 수정에 포함하지 않았습니다.
게임의 피해량, 전법 발동 확률, 포로 판정과 저장 파일을 변경하지 않습니다.

확인 범위
사용 중인 통합 호환판 R2의 실제 실행 코드와 제공된 실패 로그를 대조했습니다.
조형·색상 504개 조합, 부대정보 정리 연결, 모델 교체와 해제,
기존 기능 및 업데이트 중단 복구를 내부 검사했습니다.
이 작업 환경에서는 Windows 게임을 직접 실행하지 못했습니다.
사용자가 추가한 확장 조형 각각의 실제 화면 품질까지 검증한 것은 아닙니다.
다른 버전의 통합 패치는 확인된 범위를 벗어나면 임의로 연결하지 않습니다.

설치 후 확인
12번에서 인물 조형을 저장한 뒤, 같은 인물의 필드 조형이 바뀌는지 확인하면 됩니다.
12번을 사용하지 않을 때도 그대로 실행할 수 있습니다.

제거
게임을 종료한 뒤 이 설치 프로그램에서 ‘제거’를 누르세요.
다른 패치와 게임 저장 파일은 보존합니다.
