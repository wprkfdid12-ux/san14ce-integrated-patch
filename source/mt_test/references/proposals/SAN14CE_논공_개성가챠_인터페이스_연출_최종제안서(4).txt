SAN14 CE 논공 「개성 가챠」 인터페이스·연출 최종 제안서
대상: 삼국지14 Complete Edition 최신판(CE)
목적: 기존 논공 UI를 훼손하지 않고, 버튼 내부 연출만으로 가챠의 타격감·고점 체감·시각/사운드 만족도를 강화한다.
중요: 가챠 결과 판정 자체는 별도 최종 알고리즘 제안서 및 CE 공식 DB 분석결과를 최우선 기준으로 사용한다. 본 문서는 “보여주는 방식”만 규정한다.

============================================================
0. 최우선 구현 원칙
============================================================
1) 기존 삼국지14 CE 논공 인터페이스 유지.
2) 새 팝업, 새 오버레이, 새 별도 가챠창 금지.
3) 현재 「개성 해금」 버튼의 크기와 배치 안에서 연출을 살린다.
4) 기존 장수 초상화 위치·크기·표시 방식 변경 금지.
5) 별도 개성 설명창 추가 금지.
6) 기존 “개성 Hover 설명 패치”와 반드시 연동한다.
   - 가챠 결과가 확정되어 개성명이 표시된 뒤 해당 개성 위에 마우스를 올리면 기존 Hover 설명이 정상 출력되어야 한다.
   - 새 툴팁 시스템을 중복 구현하지 않는다.
7) 가챠 판단 로직은 CE 공식 DB 기반 알고리즘을 우선 적용한다.
   - UI가 결과를 임의 변경하거나 희귀도 확률을 별도로 조작하지 않는다.
8) 60FPS 유지 우선.
   - 논공창 밖 상시 이펙트 금지.
   - 매 프레임 무거운 확률 계산 금지.
   - 버튼 클릭 시 결과는 즉시 계산하고, 약 1.2초 연출 동안 결과를 숨겼다가 공개한다.

============================================================
1. 기본 연출 방식
============================================================
형식: 혼합형
- 초반: 슬롯머신처럼 개성명이 빠르게 순환.
- 마지막: 카드 확정처럼 한 개성이 “탁” 고정되는 느낌.
- 감속 연출은 사용하지 않는다.

이유:
- 논공 대상 장수가 많기 때문에 길고 느린 연출은 반복 플레이에서 피로감을 만든다.
- 일정한 빠른 속도로 순환하다 바로 확정되는 방식으로 템포를 유지한다.

============================================================
2. 기본 연출 시간
============================================================
목표 총 시간: 약 1.2초

권장 타임라인:
- 0.00~0.08초 : 버튼 클릭 반응 / 회전 시작
- 0.08~0.95초 : 개성명 고속 순환
- 0.95~1.10초 : 결과 등급에 따른 아주 짧은 예고 효과
- 1.10~1.20초 : 최종 개성 확정 + 펀치 효과

주의:
- 0.08~0.95초 동안 회전 속도는 의도적으로 감속시키지 않는다.
- “점점 느려지는 슬롯머신 연출” 금지.
- 전체 플레이 템포가 무거워지지 않도록 한다.

============================================================
3. 개성명 순환 연출
============================================================
- 「개성 해금」 버튼 내부 텍스트만 빠르게 교체한다.
- 버튼 바깥으로 텍스트가 튀어나오거나 대형 텍스트를 띄우지 않는다.
- 현재 삼국지14 CE의 글꼴, 글자 크기, 정렬감과 최대한 동일하게 유지한다.
- 회전 중 표시되는 개성명은 시각 연출용이며, 실제 최종 가챠 결과와 확률 계산을 변경하지 않는다.
- 같은 개성명이 회전 과정에서 반복 등장해도 무방하다.
- 가독성을 위해 너무 짧은 간격의 잔상/겹침은 금지한다.

============================================================
4. 최종 확정 펀치 연출
============================================================
최종 결과가 결정되는 순간:
1) 결과 개성명이 약 0.1초 정도 살짝 확대.
2) 즉시 원래 버튼 크기와 글자 크기로 복귀.
3) 버튼 테두리와 선광이 동시에 한 번 강조.
4) 과도한 화면 흔들림은 사용하지 않는다.

목표:
- “그냥 글자가 멈췄다”가 아니라
  “결과가 확정되었다”는 짧고 명확한 타격감 제공.

============================================================
5. 결과 유형별 색상 연출
============================================================
[청색 긍정 개성]
- 기본 청색 계열 유지.
- 짧은 청색 + 백색 테두리 광.
- 효과는 절제한다.

[금색 개성]
- 선명한 금색 + 백색 플래시.
- 버튼 테두리와 확정선이 일반 결과보다 한 단계 더 강하게 강조.
- 금빛 파티클은 작고 짧게 사용.

[이변 / 초월]
- 금빛을 기본으로 하되 적색 또는 자주색 계열 잔광 추가.
- 일반 금색과 즉시 구분되는 별도 시각 패턴 사용.
- 화면 전체 색상을 과도하게 덮지 않는다.

중요:
- 색상 차별화는 명확하게.
- 하지만 삼국지14 원작 UI를 벗어나는 네온/모바일게임 과장 연출은 금지.

============================================================
6. 속도선·광선·파티클
============================================================
허용:
- 버튼 주변의 짧은 속도선
- 소형 파티클
- 최종 확정 순간의 짧은 광선
- 금색/이변 결과에서만 강도 증가

금지:
- 화면 전체를 덮는 대형 파티클
- 초상화를 가리는 효과
- 텍스트를 읽기 어렵게 만드는 섬광
- 장시간 지속되는 잔상
- 논공창 바깥까지 퍼지는 효과

============================================================
7. 고점 예고 연출
============================================================
금색 또는 고점 결과는 마지막 약 0.2초에만 아주 짧게 예고한다.

예:
- 버튼 테두리 밝기 소폭 상승
- 평소와 다른 짧은 효과음 전조
- 금색 선광이 순간적으로 스침

목표:
“어? 이번 건 뭔가 다르다” 정도의 기대감.

금지:
- 회전 초반부터 금색 당첨 여부가 노출되는 것
- 결과를 너무 일찍 확정적으로 알려주는 것

============================================================
8. 이변 / 초월 전용 연출
============================================================
이변/초월은 일반 금색과 구분되는 전용 연출을 사용한다.

권장:
- 최종 확정 직전 아주 짧은 특수 선광
- 금색 + 적/자주 잔광
- 일반 금색과 다른 전용 확정 효과음
- 최종 확정 순간의 선명한 1회 강조

단:
- 별도 팝업, 별도 컷인, 전체화면 연출은 금지.
- 기존 논공창과 버튼 구조 안에서 처리한다.

============================================================
9. 사운드 설계
============================================================
기본 방향:
- 삼국지14 원작 UI 분위기 유지.
- 고점에서만 가챠 특유의 쾌감 강화.

필요 사운드 단계:
1) 버튼 클릭
2) 고속 회전 시작/진행
3) 일반 결과 확정
4) 금색 결과 확정
5) 이변/초월 결과 확정
6) 재추첨 실행

감속 연출을 사용하지 않으므로 “감속 전용 사운드”는 만들지 않는다.

사운드 성향:
- 기본: 원작 UI와 어울리는 절제된 금속음/확정음
- 금색: 기본 확정음보다 밝고 선명한 상승감
- 이변/초월: 짧고 강한 차별화
- 모바일 가챠처럼 과도한 전자음 사용 금지

============================================================
10. 리롤(재추첨) UI
============================================================
명칭: 「재추첨」

표시 방식:
- 남은 횟수 숫자 표시
- 작은 아이콘/토큰 표시 병행
- 장수당 3칸 전체 공유 5회라는 기존 알고리즘을 그대로 반영

재추첨 시:
- 이전 결과는 즉시 소멸
- 동일 개성 재등장 가능
- 확률 보정 없음
- 열기 상승 없음
- 재추첨 전 결과로 복귀 불가

연출:
- 재추첨 버튼 클릭 시 짧은 전용 효과음
- 다시 동일한 1.2초 가챠 연출 시작
- 리롤이라고 해서 더 좋은 시각 효과를 미리 주지 않는다

============================================================
11. 일반 장수 슬롯 부족: 승계 가챠 UI
============================================================
개성 슬롯이 가득 찬 일반 장수는 기존 개성 하나를 먼저 승계 대상으로 선택한다.

확인 문구 핵심:
“선택한 개성은 최종 가챠 결과물과 교체되어 사라집니다.”

반드시 전달해야 할 의미:
- 기존 개성은 최종 결과와 교체됨
- 되돌리기 불가
- 재추첨을 해도 원래 개성으로 복귀 불가

문구는 짧고 명확하게.
불필요한 장문의 경고 팝업 금지.

============================================================
12. 스타 장수 슬롯 부족: 안전 교체 UI
============================================================
스타 장수는 결과를 먼저 확인한 뒤:
- 기존 개성 하나와 교체
- 또는 새 결과 포기

스타 특전은 은근하게 표시한다.

권장:
- 작은 금색 문구
- 예: 「스타 무장 특전」
- 기존 논공 UI를 해치지 않는 수준

금지:
- 대형 배너
- 별도 특전 창
- 초상화 변경
- 별도 스타 전용 화면

포기해도 해당 개성 해금 기회 1회는 소비된다.

============================================================
13. 초상화 및 기존 UI 자산
============================================================
현재 논공창에 이미 존재하는 장수 초상화는 그대로 사용한다.

금지:
- 초상화 확대
- 새로운 상체 이미지 추가
- 새로운 장수 카드 생성
- 초상화 위치 이동
- UI 공간 확장

가챠 연출은 현재 화면의 개성 해금 버튼 영역을 중심으로만 강화한다.

============================================================
14. 개성 설명 처리
============================================================
별도 설명창은 추가하지 않는다.

이유:
- 이미 “개성에 마우스 커서를 올리면 설명이 뜨는 Hover 패치”가 존재한다.
- 새 설명창을 추가하면 기능이 중복되고 화면이 복잡해진다.

필수 연동:
- 가챠 확정된 신규 개성도 기존 Hover 패치에서 즉시 인식되어야 한다.
- 일반 화면, 논공 결과 버튼/개성 표시 영역 모두 기존 Hover 설명 규칙을 그대로 사용한다.
- 개성 효과 수치까지 기존 설명 데이터 그대로 보여야 한다.

============================================================
15. 배경 및 논공창 처리
============================================================
기존 논공창 유지.

금지:
- 배경 암전 오버레이
- 새 배경
- 별도 가챠 레이어
- 화면 전체 블러 추가
- 논공창 크기 변경

기존 삼국지14 CE 논공 화면 자체를 그대로 유지하고,
버튼과 그 주변 최소 영역만 시각적으로 반응시킨다.

============================================================
16. 스킵 규칙
============================================================
일반 결과:
- 사용자 입력으로 연출 스킵 가능
- 즉시 최종 결과 표시

금색 / 고점 / 이변 / 초월:
- 완전 즉시 스킵은 금지
- 최소 약 0.6초의 핵심 연출은 보여준 뒤 결과 표시 가능

목표:
- 반복 플레이 피로도 감소
- 고점의 가치와 존재감은 유지

============================================================
17. 추가 확정 규칙
============================================================
적용:
- 결과 확정 순간 개성명이 들어간 버튼 테두리도 동시에 짧게 강조
- 금색 개성은 일반보다 테두리/선광을 더 선명하게
- 재추첨 버튼은 결과가 확정된 후에만 활성화
- 계산은 버튼 클릭 즉시 끝내고 남는 1.2초를 연출에 사용
- 논공창 밖 상시 이펙트 금지
- 연출 중 불필요한 게임 로직 반복 호출 금지
- 60FPS 유지 우선

미적용:
- 별도 개성 설명 슬라이드/설명 패널
- 초상화 확대
- 팝업 가챠 화면
- 감속 연출
- 감속 사운드
- 전체화면 화면 흔들림

============================================================
18. CE 공식 DB 우선 연동
============================================================
이 UI는 “결과를 보여주는 계층”이다.
가챠 결과 판정은 반드시 별도 최종 알고리즘과 CE 공식 DB 분석결과를 사용한다.

참고 데이터:
- 공식 무장 1000명 DB
- 공식 보너스/고대 무장 보조 DB
- CE 개성 마스터
- 고유전법 기반 스타 플래그
- 혈연 데이터
- DLC/콜라보 데이터(해독 완료 범위)

UI 코드가 자체적으로:
- 무력형/지력형 분류
- 상급/하급 분류
- 황금 확률 별도 수정
- 특정 개성 강제 삽입
을 해서는 안 된다.

확률/가중치/고점 체감 수치는 앞으로 실제 CE DB 기반 시뮬레이션 결과를 보고 별도 조정한다.

============================================================
19. 구현 완료 검증 체크리스트
============================================================
[ ] 기존 논공 화면 구조가 변하지 않았는가
[ ] 버튼 크기/배치가 원본과 동일한가
[ ] 기본 연출이 약 1.2초인가
[ ] 감속 없이 빠른 순환→즉시 확정 구조인가
[ ] 일반/금색/이변·초월의 색·사운드가 구분되는가
[ ] 고점 예고가 마지막 약 0.2초에만 나타나는가
[ ] 최종 글자 펀치 효과가 과하지 않은가
[ ] 초상화가 전혀 변경되지 않았는가
[ ] 별도 개성 설명창이 생기지 않았는가
[ ] 기존 Hover 설명 패치와 신규 개성이 정상 연동되는가
[ ] 재추첨 5회 공유 상태가 정확히 표시되는가
[ ] 일반 장수 승계 경고가 정확한가
