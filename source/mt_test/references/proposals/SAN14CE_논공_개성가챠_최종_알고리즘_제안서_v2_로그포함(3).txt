SAN14 CE 논공 「개성 가챠」 최종 알고리즘 제안서
버전: Final Design Draft
목적: Astra/개발 작업용. 구현 방향이 다른 곳으로 새지 않도록 핵심 규칙만 고정한다.
주의: 아래의 확률·가중치·임계값 수치는 “고정 확정값”이 아니다. 실제 코에이 데이터 기반 시뮬레이션 결과를 보고 조정할 수 있도록 중앙 파라미터화한다.

============================================================
0. 최종 목표
============================================================
- 논공의 기존 지휘병사 증가 3칸을 장수당 평생 3회의 「개성 해금」으로 교체한다.
- 1/2/3번째 칸은 모두 동일하다. 3번째 황금 확정, 단계별 등급 고정 등은 사용하지 않는다.
- 플레이어와 AI 모두 동일한 기본 가챠 시스템을 사용한다.
- “그 장수다운 성장”을 기본으로 하되, 극저확률 이변으로 예상 밖 결과도 허용한다.
- 개성 인플레를 장수 총인원수로 제한하지 않는다. 신무장이 몇 명 추가되든 장수 1명당 평균 성장량을 제어한다.
- 매 프레임 계산 금지. 개성 해금 버튼 클릭 시 1회 계산하고, 약 1초 연출 중 이미 결과를 확정한다.

============================================================
1. 가장 중요한 원칙: 수동 직업/등급 분류 금지
============================================================
금지:
- “무력형/지력형/정치형” 같은 수동 분류로 개성 방향 결정
- “평범/괜찮음/상급” 같은 수동 개성 등급표
- 개성별로 사람이 임의의 통/무/지/정 성향값 부여
- 특정 유명 장수마다 개별 확률표 수작업 작성

사용:
- 대상 장수의 통솔/무력/지력/정치 전체 형태
- 대상 장수의 현재 보유 개성
- 공식 무장 데이터에서의 유사 장수
- 각 공식 무장이 실제로 보유한 개성
- 코에이 공식 데이터의 황금 여부, 고유전법 여부, 혈연 등 객관적 플래그

즉 “강유에게 무엇이 어울리는가?”를 사람이 정하지 않고, 공식 장수 데이터가 정하도록 한다.

============================================================
2. 기준 데이터 풀
============================================================
[가챠 대상]
- 현재 게임에 실제 존재하는 모든 사실무장
- 사용자가 만든 신무장도 가챠 대상 가능

[유사도 판단용 교사 데이터]
- 공식 순정 삼국지 무장
- 설치/마스터 데이터에서 확인 가능한 공식 DLC·콜라보 무장
- 신무장은 기본적으로 교사 데이터에서 제외
  → 사용자가 100/100/100/100 신무장을 대량 생성해도 순정 장수의 확률표가 오염되지 않게 한다.

[DLC/콜라보]
- 순정 개성과 별도의 성향 규칙을 만들지 않는다.
- 공식 DLC/콜라보 개성도 일반 개성과 동일한 적합도 엔진으로 처리한다.
- DLC 캐릭터가 현재 시나리오에 등장하지 않아도 공식 마스터 프로필이 설치 데이터에 존재하면 참고 표본으로 사용 가능.
- 해당 개성 정의 자체가 현재 설치환경에 없으면 지급 후보에서 제외한다.

============================================================
3. 개성 적합도 계산
============================================================
개성 해금 버튼을 누르면:

1) 대상 장수의 통/무/지/정 + 현재 개성을 읽는다.
2) 공식 교사 데이터의 모든 장수와 유사도를 계산한다.
3) 유사도가 높은 장수들이 실제 보유한 개성에 더 높은 후보 가중치를 준다.
4) 이미 대상 장수가 보유한 동일 개성은 제외한다.
5) 새로 얻은 1번째 개성은 2번째 계산에 약하게 반영,
   1·2번째 개성은 3번째 계산에 약하게 반영한다.
   단, 새 획득 개성의 영향은 본래 캐릭터성을 뒤집지 않을 정도로 제한한다.

중요:
- “문인/무인/무력형/지력형” 중간 분류를 만들지 않는다.
- 장수 개인의 전체 데이터 형태를 그대로 비교한다.

============================================================
4. 1인 전용·고유개성 처리
============================================================
순정/DLC 구분 없이 동일 규칙.

- 보유자가 여러 명인 개성:
  → 해당 보유자들의 분포를 종합해 적합도 형성.

- 보유자가 1명뿐인 개성(예: 고유 황금개성 포함):
  → 원본 보유자를 핵심 앵커로 사용.
  → 원본 보유자와 유사한 공식 무장군을 보조 참고한다.

예:
- 간웅: 조조가 핵심 앵커
- 탈토: 유비가 핵심 앵커
- 콜라보 1인 전용 개성: 해당 공식 캐릭터가 핵심 앵커

DLC라서 별도 취급하지 않는다.

============================================================
5. 적합도 / 황금 / 희소도 / 성장비용은 서로 분리
============================================================
서로 같은 개념으로 합치지 않는다.

- 적합도:
  “이 장수에게 얼마나 어울리는가?”
  → 유사 장수 데이터가 결정

- 황금 여부:
  코에이 공식 데이터의 특수 등급
  → 고점/성장비용에 큰 영향

- 희소도:
  공식 기준 데이터에서 보유자가 얼마나 드문가
  → “강함” 판정에 쓰지 말고, 동일 개성의 과도한 복제 억제용으로만 약하게 사용

- 성장비용:
  한 장수가 3회 동안 강개성을 연속으로 과다 획득하지 않게 하는 내부 비용

수동으로 “질풍 80점, 통찰 95점” 같은 등급표는 만들지 않는다.

============================================================
6. 장수별 개인 성장예산
============================================================
세계 전체 “황금 N개 제한”은 사용하지 않는다.
신무장 수가 유저마다 다르기 때문이다.

대신 장수 1명마다 3회 전체를 관통하는 숨은 개인 성장예산을 둔다.

- 큰 고점/황금 결과 획득 → 성장예산을 많이 소비
- 낮은 결과 → 적게 소비
- 앞에서 대박이 터지면 뒤에서 연속 대박 확률이 자연스럽게 낮아짐
- 앞에서 낮은 결과가 이어지면 뒤쪽에 여유가 남음
- 황금→황금→황금은 금지하지 않되 극히 희귀하게 유지

기존에 강한 개성을 많이 가진 장수는 추가 고점 비용을 약하게 높여 폭주를 억제한다.
단, 강한 장수에게 계속 쓰레기만 나오게 하는 역보정은 금지한다.

============================================================
7. 열기(저점 보상)
============================================================
낮은 결과를 실제로 “확정해서 받아들였을 때”만 열기를 조금 올린다.

- 저점 확정 → 열기 상승 → 이후 고점 가능성 소폭 증가
- 저점 리롤 폐기 → 열기 상승 없음
- 열기는 천장이 아니다. 좋은 결과 확정을 보장하지 않는다.

============================================================
8. 이변 / 초월
============================================================
캐릭터 컨셉을 100% 고정하지 않는다.

- 정상 추첨:
  유사도 기반 적합도 규칙을 강하게 준수

- 이변:
  극저확률로 적합도 제한을 크게 완화
  → 감녕에게 복룡, 여포에게 통찰 같은 비정상 조합도 “0%는 아님”

- 초월:
  더 희귀한 특수 판정
  → 개인 성장예산 등의 제한을 일부 돌파할 수 있음

중요:
“복룡 1%” 같은 개별 확률을 직접 주지 않는다.
먼저 이변/초월을 통과한 뒤 전체 후보 중에서 다시 선택되므로 특정 기묘한 조합의 실제 확률은 훨씬 낮아야 한다.

============================================================
9. 스타 무장
============================================================
기본 스타 판정:
- 코에이 공식 데이터에서 “고유전법 보유” 플래그를 기준으로 한다.

주의:
- 문인/무인으로 다시 나누지 않는다.
- 고유전법의 의존 능력(무력/지력)으로 개성 방향을 결정하지 않는다.
- 스타 플래그는 “무슨 개성이 어울리는가”를 바꾸지 않고 “가챠 대우”만 바꾼다.

스타 효과:
1) 기본 유사도/적합도 엔진은 일반 장수와 동일
2) 유사 장수 상위권의 영향력을 조금 더 선명하게 적용하여 캐릭터 컨셉 유지
3) 고점 가능성을 일반 장수보다 높일 수 있음
4) 슬롯 부족 시 일반 장수와 다른 “안전 교체” 권한 사용

황금 확정은 기본 규칙으로 두지 않는다.
스타 보정의 강도는 시뮬레이션으로 조정한다.

============================================================
10. 혈연 보정
============================================================
유명 부모의 자식이 부모 복제품이 되지 않도록 약한 보정만 준다.

- 본인 데이터가 항상 주축
- 부모의 성장 성향을 약하게 혼합
- 조부모는 부모보다 더 약하게 반영
- 황금 확정 상속 금지
- 여러 혈연 보정이 무한 중첩되지 않도록 상한 설정

예:
조광은 조광 자신의 능력치/기존 개성이 기본이며,
조운의 성향이 “약한 보조 가중치”로만 들어간다.

============================================================
11. 리롤
============================================================
장수 1명당 개성 3칸 전체에서 공유 리롤 5회.

규칙:
- 3칸 공용 5회. 슬롯별 별도 지급 아님.
- 한 슬롯에 5회를 전부 써도 됨.
- 그러면 나머지 슬롯은 리롤 0회.
- 리롤 시 이전 결과는 즉시 소멸. 되돌리기 불가.
- 이전 결과를 후보에서 제외하지 않는다.
- 동일 개성이 다시 나올 수 있다.
  예: 흉노 → 리롤 → 흉노 가능.
- 리롤 자체에 고점 보정 없음.
- 리롤 자체에 열기 상승 없음.
- 리롤 결과가 이전보다 나빠질 수 있음.
- 5회는 “좋은 결과 5개 중 선택”이 아니라 진짜 재추첨이다.
- 5회 사용량은 장수의 3회 해금 상태와 함께 저장한다.

AI도 동일하게 5회 사용.
AI의 리롤 판단은 수동 개성 등급표가 아니라 현재 후보 분포 내 적합도/황금 여부/성장상태 등의 알고리즘 점수로 처리하며 임계값은 시뮬레이션으로 조정한다.

============================================================
12. 개성 슬롯 부족 시 처리
============================================================
개성 획득은 평생 3회뿐이다.

[빈 슬롯이 있으면]
- 정상적으로 추가 획득

[빈 슬롯이 없으면: 일반 장수]
→ “승계 가챠”
1) 가챠 전에 기존 개성 1개를 승계 대상으로 지정
2) 가챠 + 리롤 진행
3) 최종 결과가 나오면 지정한 기존 개성을 최종 결과로 교체
4) 원래 개성으로 복귀 불가
5) 리롤 5회 규칙은 동일

[빈 슬롯이 없으면: 스타 장수]
→ “안전 교체”
1) 먼저 가챠 + 리롤을 전부 진행
2) 최종 결과를 확인
3) 기존 개성 1개와 교체하거나 새 결과를 포기
4) 포기해도 해당 개성 해금 기회 1회는 소비
5) 좋은 결과가 나올 때까지 같은 해금칸을 반복하는 것은 금지

스타의 낭만/컨셉을 보호하는 특전은 “결과를 보고 교체 여부 결정”으로 표현한다.
원래 보유 개성 보호/잠금 시스템은 도입하지 않는다.

============================================================
13. 시작부터 지휘병사 +500/+1000 보상이 채워진 시나리오 예외
============================================================
가정하지 말고 실제 해당 공로효과 플래그를 읽는다.
공로 랭크만 보고 추정하지 않는다.

기존 지휘병사 증가 3칸을 개성 해금으로 교체할 때:
- 원본 세이브/시나리오의 공로 랭크와 진행 상태 자체는 유지
- 대상 지휘병사 증가 효과는 패치에서 무효화
- 해당 보상 플래그가 시작부터 이미 활성화되어 있으면
  → 대응하는 “개성 해금권”을 시작부터 활성화하되
  → 아직 추첨하지 않은 상태로 표시
- 이미 추첨했는지는 모드 sidecar 상태로 별도 저장
- 재로드/재진입 시 중복 지급 금지
- 원본 +500/+1000과 새 개성이 동시에 적용되는 이중 보상 금지

즉:
“이미 얻은 지휘병사 보상”은 “이미 열린 개성 해금권”으로 변환한다.
원본 데이터 필드에 개성 ID를 억지로 덮어쓰지 않는다.

============================================================
14. 저장/호환/성능
============================================================
- 원본 EXE/데이터 통째 교체 금지
- 다른 패치 파일 덮어쓰기 금지
- 공통 Core/Loader + 기능 독립 DLL 원칙 유지
- 시그니처/패턴 스캔 우선, 버전 감지
- 오프셋/후킹 계층 분리
- 가챠 상태는 sidecar 저장
  (3칸 해금/추첨 여부, 잔여 리롤, 성장예산/열기 등 필요한 최소 상태)
- 공식 업데이트 시 Resolver/Core 수정만으로 대응 가능하게 설계

성능:
- 게임 시작/세이브 로드 시 공식 장수 데이터 캐시
- 개성 해금 버튼을 눌렀을 때만 1회 계산
- 논공창 대기 중 상시 계산 금지
- 매 프레임 계산 금지
- 목표: 버튼 클릭 후 수십 ms 이내 결과 확정
- 기존 약 1초 “띠리리” 연출 중 계산 완료, 1초 후 결과 공개
- FPS 60 유지 목표

============================================================
15. 수치 튜닝 원칙
============================================================
현재 단계에서 아래 수치는 확정하지 않는다.
- 유사도 계산식의 세부 가중치
- 기존 개성 반영 비율
- 신규 획득 개성의 다음 가챠 영향률
- 스타 보정 강도
- 혈연 보정률
- 성장예산 크기/소비량
- 기존 강개성 보유 패널티 강도
- 희소도 복제 억제 강도
- 열기 상승폭
- 이변/초월 확률
- AI 리롤 임계값

이 값들은 실제 코에이 전체 공식 무장/개성 데이터로 가상 시뮬레이션을 반복해:
1) 특정 장수의 캐릭터성이 유지되는지
2) 저점/고점 차이가 충분한지
3) 황금 개성 인플레가 과한지
4) 스타 장수의 육성맛이 좋은지
5) 일반 장수도 성장 가능성이 살아있는지
6) 신무장 수가 변해도 평균 성장량이 안정적인지
를 보고 조정한다.

수치는 한 곳의 중앙 파라미터 테이블에서 관리해 튜닝 가능하게 한다.
유저에게 INI/주소/수동 편집을 요구하지 않는다.

============================================================
16. 구현 시 금지사항 요약
============================================================
- 3번째 칸 황금 확정 금지
- 빨간 부정 개성 기본 지급 금지
- 문인/무인 분류로 개성 후보 결정 금지
- 최고 능력치 하나만 보고 계열 결정 금지
- 개성별 수동 통/무/지/정 성향값 금지
- 수동 “하급/중급/상급” 등급표 금지
- 순정 1000명 기준 세계 황금 총량 제한 금지
- 신무장을 유사도 교사 데이터에 섞어 공식 분포 오염 금지
- 리롤에서 이전 결과 보존/양자택일 금지
- 리롤할수록 확률 상승 금지
- 매 프레임/상시 분석 금지
- 원본 공로 데이터 필드에 개성 ID 직접 덮어쓰기 금지
- 스타라는 이유로 전체 황금 풀에서 무작위 추첨 금지

17. 진단·밸런스 로그 시스템
============================================================
목적:
- 알고리즘이 왜 특정 결과를 냈는지 추적한다.
- 실제 플레이/AI 결과를 모아 가중치·확률을 시뮬레이션 후 조정한다.
- 이상한 결과, 과도한 황금 인플레, 스타 보정 과다/부족, 혈연 보정 오류 등을 원인 단위로 확인한다.

[기본 원칙]
- 로그는 패치 기본 기능으로 포함한다.
- 매 프레임 기록 금지.
- 개성 해금, 재추첨, 최종 확정, 승계/안전교체, AI 재추첨 판단 등 “사건 발생 시”에만 기록한다.
- 로그 기록 때문에 60FPS 또는 1.2초 가챠 연출이 지연되어서는 안 된다.
- 게임 원본 세이브를 수정하지 않고 모드 전용 로그 폴더에만 기록한다.

[가챠 1회 기록 항목]
- 모드 버전 / CE 게임 버전 / 시나리오·세이브 식별값
- 사건 ID와 시각
- 무장 ID / 이름 / 순정·DLC·신무장 구분
- 통솔 / 무력 / 지력 / 정치 / 매력
- 현재 보유 개성
- 현재 개성 슬롯 수
- 고유전법 기반 스타 여부
- 혈연 보정 적용 여부 및 참고 부모/조부모
- 유사 장수 상위군과 각 유사도 점수
- 최종 후보 개성 상위 가중치 목록
- 선택된 개성의 원시 가중치 / 최종 가중치
- 금색 여부 / 희소도 보정
- 성장예산: 추첨 전 / 추첨 후
- 열기: 추첨 전 / 추첨 후
- 이변 여부
- 초월 여부
- 현재 해금 칸(1/2/3)
- 재추첨 횟수 및 잔여 횟수
- 일반 장수 승계 대상 개성
- 스타 장수 안전교체/포기 여부
- 최종 획득 개성
- AI일 경우 재추첨 여부와 내부 판단값
- 해당 가챠 계산 소요시간(ms)

[재현성]
- 각 추첨에 고유 Roll ID를 부여한다.
- 디버그 분석을 위해 난수 판정값 또는 재현 가능한 seed/seed hash를 기록한다.
- 같은 Roll ID의 “최초 결과 → 재추첨 → 최종 확정” 흐름을 한 묶음으로 추적 가능해야 한다.

[로그 형식]
- 사람이 읽기 쉬운 요약 TXT와 분석용 JSONL 중 하나 또는 둘 다 사용 가능.
- 개발/시뮬레이션용 원본은 구조화된 JSONL을 우선한다.
- 한 줄/한 레코드가 한 사건을 나타내도록 하여 자동 통계 분석이 가능하게 한다.

[용량 관리]
- 무제한 누적 금지.
- 순환 로그(rolling log) 사용.
- 파일별 용량 상한과 보관 개수 상한을 둔다.
- 오래된 로그는 자동 교체한다.
- 로그 파일 때문에 게임 폴더가 수백 MB~수 GB로 계속 커지는 구조 금지.

[사용자 조작]
- INI, 메모장, 함수 주소, 명령어 입력을 요구하지 않는다.
- 패키지에 “가챠 로그 추출” 원클릭 도구를 포함한다.
- 실행하면 현재 관련 로그만 자동 수집해 ZIP 하나로 만든다.
- 사용자는 그 ZIP만 전달하면 분석 가능해야 한다.
- 로그 기능 ON/OFF 또는 상세도 변경이 필요하면 GUI/버튼으로 제공하고 수동 설정파일 편집을 요구하지 않는다.

[성능]
- 후보 계산 완료 후 로그 데이터를 메모리에 조립하고 짧게 append하는 방식 우선.
- 무거운 전체 DB 재검색이나 파일 스캔을 로그 때문에 다시 수행하지 않는다.
- 로그 기록 실패 시 가챠 자체는 정상 진행되어야 한다.
- 로그 I/O 오류가 게임 튕김으로 이어지지 않게 예외 처리한다.

[밸런스 조정 활용]
로그를 모아 다음 값을 후속 시뮬레이션으로 조정할 수 있어야 한다.
- 유사도 가중치
- 기존 개성 반영률
- 신규 획득 개성의 후속 영향률
- 스타 보정 강도
- 혈연 보정 강도
- 성장예산 크기/소비량
- 열기 보정
- 희소도 복제 억제
- 이변/초월 확률
- AI 재추첨 판단 임계값

중요:
- 현재 수치는 최종 고정값이 아니다.
- 실제 CE 공식 DB 기반 시뮬레이션 + 실플레이 로그를 보고 보정한다.
- 로그는 확률을 바꾸는 기능이 아니라 “왜 그런 결과가 나왔는지 확인하는 관측 계층”이다.

18. 최종 한 줄 정의
============================================================
“공식 장수 데이터에서 대상 장수와 유사한 무장들을 찾아 그들이 실제 가진 개성을 기반으로 후보를 자동 구성하고, 개인 성장예산·열기·스타·혈연·희귀 이변을 결합해 3회의 개성 가챠를 제공하며, 5회 공유 리롤과 슬롯 부족 시 일반=승계 / 스타=안전교체를 적용하고, 모든 주요 판정 근거를 진단 로그로 남겨 실제 시뮬레이션과 플레이 결과를 토대로 지속 튜닝할 수 있는 데이터 기반 논공 성장 시스템.”
