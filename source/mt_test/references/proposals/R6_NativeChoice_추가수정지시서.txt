RC4-R6-NativeChoice 추가수정지시서 — 기존 우리 R5-SafeExit_Confirm의 이어 작업
2026-09-19. 원본 제안서에 합치지 않는 별도 변경 지시서.

최신 지시 우선순위
이 문서의 뒤로가기 규칙은 R5의 '뒤로 예=결과 확정'을 폐기하고 대체한다.
다른 채팅방의 영상/로그는 위험 사례 참고 자료다. 그 버전의 소스를 기준으로 새로 만들지 않는다.

1. 논공 보상 선택은 원작 그대로
지휘병사 증가 보상만 개성 해금으로 바꾼다. 윗줄과 아랫줄이 현재 공로랭크의
선택 가능 횟수를 공유한다. 최종 상한은 합계 3칸이며 각 줄은 왼쪽부터 선택한다.
아랫줄 2칸이 이미 확정된 조운은 윗줄 첫 개성칸 또는 아랫줄 셋째 정책칸 중
하나만 추가 선택한다. 윗줄 둘째·셋째 가챠는 허용하지 않는다.
보상 상태는 무장 ID별, 윗줄 기회별 결과/선택/교체 대상으로 나누어 관리한다.
'숙련/노련/중진마다 고정된 세로 열 하나를 고른다'는 새 규칙을 만들지 않는다.
두 줄의 선행 선택·공유 한도는 원작 선택 기록이 결정한다.

2. 선택 표시와 확정
처음 해금 추첨에 성공하면 해당 보상을 원작 선택 기록에 등록한다.
추첨된 개성칸은 내정 보상과 같은 원작 선택 색상을 사용한다.
결과칸을 다시 누르는 선택 해제/재선택은 원작 라디오 동작을 따른다.
재선택으로 결과를 새로 뽑거나 재추첨권을 되돌리지 않는다.
원작의 선택 조건을 채우면 하단 결정이 활성화되고, 실제 효과는 결정 성공 후 반영한다.
상단 확정·나감 버튼과 클릭 영역은 없다.

3. 뒤로/ESC
아직 미확정인 추첨 결과가 있으면 게임 패널/버튼 모양의 예·아니오 경고:
  뒤로 나가면 아직 확정하지 않은
  개성 추첨 결과가 초기화됩니다.
  사용한 재추첨권은 복구되지 않습니다.
  진행하시겠습니까?
예: 미확정 결과와 화면의 임시 선택을 버린 뒤 원작 취소 경로로 나간다.
    논공 비용·공로랭크·개성·꽝 X·열정은 적용하지 않는다.
아니오: 현재 결과·임시 선택·남은 개인권 그대로 화면에 복귀한다.
이미 결정으로 얻은 개성과 보상은 건드리지 않는다.
경고 안에서 새로 누른 ESC는 아니오. 누르고 있던 키/마우스와 Enter는 자동 동의가 아니다.
아직 뽑지 않은 승계 선택만 있으면 보상/비용 없이 원작 취소한다.

4. 개인 재추첨권
장수 1명당 자신의 기회 전체에서 총5개. 다른 장수·페이지와 공유하지 않는다.
성공한 재추첨 즉시 해당 장수에게 예약 차감. 뒤로/강제 화면 해제 후에도 차감 유지.
재추첨 실패에는 차감하지 않는다. 결정 때 예약분과 슬롯 사용량을 한 번만 정산한다.
저장·로드는 저장된 개인 권수와 확정 결과를 따른다. 예전 세이브 반복 로드는 막지 않는다.

5. 9칸 교체
기존 일반 승계/스타 교체 규칙을 유지한다. 실제 개성 교체가 필요한 상태로 결정을
누르면 무장·기존 개성·새 개성을 보여주고 예·아니오로 확인한다.
여러 교체는 각각 확인한 뒤 한 번의 원작 결정으로 처리한다.
아니오/경고 생성 실패는 실제 개성을 변경하지 않는다.
경고 도중 원작 선택 기록이 달라지면 실제 교체 목록을 재대조해 바뀐 교체는 다시 확인한다.
꽝/획득 포기는 기존 개성을 지우는 교체 확인으로 취급하지 않는다.

6. 버튼과 입력
'계산 근거 펼치기'는 '계산 근거' 한 줄만 남긴다. 버튼 중앙 정렬, 선택과 같은 글꼴.
재추첨 버튼 높이·세로 위치·글꼴도 원작 선택에 맞춘다.
경고는 원작 패널/버튼 리소스를 쓰고, 본문은 패널의 읽을 수 있는 고유 글자색 유지.
오래된 callback, 다른 무장으로 바뀐 callback, 비활성/숨은 버튼, 포커스 밖 입력은 거부.
원작 callback이 빠지는 경우 게임 논리 좌표와 UI 소유 관계를 확인한 클릭만 보완한다.
중복 클릭/지연 callback이 한 번의 조작을 두 번 실행하지 않아야 한다.
화면 해제는 callback 무효화→입력 등록 해제→원래 리소스 컨텍스트로 정리 순서.

7. 유지
공식 대상/비교 무장의 능력치 분포는 원본 DB. 현재 편집/성장 능력치는 수정하지 않는다.
기존 개성9칸/Hover/확인된 RC25 프리셋 연결, 꽝 X·열정·평가·저장 v3·AI는 유지.
내정 보상 때문에 마지막으로 가능한 윗줄 기회가 첫째/둘째가 된 경우에도 마지막은 꽝 없음.
실게임에서 확인하지 않은 종료 안정성·폰트 렌더·모든 외부 패치 호환을 보장하지 않는다.
