# 논공 개성 가챠 RC4 R2 — 검증 결과

첨부 인계의 R1 소스에서 이어 구현·재빌드한 설치 후보입니다. 실게임 검증 완료판은 아닙니다.

## 최종 능력치 규칙

공식 대상 무장과 비교 상대 모두 **원래 DB 능력치**를 비교합니다. 조광(ID619)의 입력은
65/68/53/51/60입니다. 실제 능력치를 99/98/97/96/95로 바꿔도 후보 확률은 같고,
하단 결정 후에도 실제 게임 능력치는 유지되는 것을 검사했습니다.
통솔·무력·지력·정치의 분포를 비교하며 5개 능력치를 표시합니다. DB가 없는 신무장만 현재 기본값을 씁니다.
현재 보유 개성·고유전법·부모 정보에는 이 원본 능력치 규칙을 확대하지 않았습니다.
기존 저장의 추첨 결과를 다시 뽑지 않습니다. 앞으로 계산하는 추첨에 적용됩니다.

## 변경

- 기존 해금칸 클릭 즉시 추첨. 기존 3칸 위치와 원작 잠금 보존.
- 별도 원작 네이티브 재추첨·확정·승계/교체·취소 버튼.
- 선택은 미리보기 상태에 보관하고 원래 하단 결정에서 실제 반영.
- 완료칸 클릭과 입력 해제의 자동 감사 제거. 합성 state 변경/재귀 tick 제거.
- row 자원 정리(vslot 0x28)의 두 번째 인자 전달 누락 수정.
- 왼쪽 접이식 계산 근거, 내부 스크롤, 계산 스냅샷. 열기/닫기에 RNG·후보 재계산 없음.
- 연출 중 계산 근거·Hover의 결과 선노출 차단. 설명용 상대 평가 v1.
- 이미 지급된 원작 해금권은 추가 비용 없이 처리. 저장 스키마·두 세대 복구 유지.

| 저장 슬롯·Steam ABI·원작 UI·AI·연출 | 76 |

| R2 이벤트·별도 버튼·재진입·원본 DB 능력치·평가 | 65 |
| 패키지·PE·재현 빌드·설치/복원 스크립트 정적 검사 | 99 |

**DLL assertion 245개, 별도 정적 assertion 99개.** 실제 Win64 코드를 Linux에서 실행하되
OS·Steam·게임·위젯 접점을 대체했습니다. 실게임 테스트 시나리오 수가 아닙니다.
R1의 칸 재사용/입력 해제 감사 기대값은 R2 동작으로 이관했습니다. 이전 사본은 tests/r1_baseline에 있습니다.
이전 R1 보고서는 이번 통과 수에 포함하지 않습니다.

공용 dxgi·Core·기본 Resolver·Hover 4개는 R1과 동일합니다. 논공 DLL 및 전용 Resolver는 재빌드했고,
검사한 DLL과 payload 해시가 일치합니다. R1 해시를 업그레이드 목록에 추가했으며 알 수 없는 파일 보호는 유지합니다.
Zig 빌드는 SOURCE_DATE_EPOCH=0을 사용합니다. 스택 검사는 현재 DLL 심벌을 사용하고 이전 map을 참조하지 않습니다.

## 평가 및 시뮬레이션

평가식 v1은 100×(0.50×가치 + 0.25×놀라움×가치 + 0.15×희소성 + 0.10×특수성)입니다.
후보 상대 적합도와 공식 황금 플래그를 사용하고, 낮은 적합도의 희귀 결과에는 상한을 둡니다.
경계는 25/45/65/82/95이며 평범/무난/의외/대박/파격/충격 순입니다.
초월·이변 예외에도 가치·적합도 조건이 필요합니다. 설명용 초기 튜닝이며 개성 성능의 확정 등급표가 아닙니다.
같은 C 엔진의 공식 1000명×3회 고정 시드 시뮬레이션은 audit/rc4_simulation.json에 있습니다.
이 계산 시간은 게임 FPS나 실플레이 장기 분포가 아닙니다.

## 남은 확인

실제 Windows 설치·복원·제거, Steam/게임 저장·로드, 버튼의 실화면 위치와 자원 수명,
충돌 재현 장면, DirectX·음향·60FPS는 확인하지 못했습니다. 현재 검사는 이를 대체하지 않습니다.
예상한 여백 범위가 다르면 버튼과 추첨을 활성화하지 않습니다. 실제 화면에서 버튼이 나타나는지도 확인이 필요합니다.
미확정 선택 중 저장을 막으며 상세 스냅샷은 실행 세션에만 유지합니다. 이전 저장은 재계산 없이 결과 요약을 표시합니다.
보조 정보는 Steam Cloud 자동 동기화 대상이 아니며, 매핑 미확인 DLC 황금 39종은 후보에 추가하지 않았습니다.
