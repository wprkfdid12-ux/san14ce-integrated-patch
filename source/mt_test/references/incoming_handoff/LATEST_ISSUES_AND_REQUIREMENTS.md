# RC4 R2 최신 실게임 피드백 요약

## 치명적 버그
가챠 결과가 확정된 개성 해금 칸을 클릭했더니 원래 순정 장수 일러스트와 감사 대사가 먼저 실행되고, 직후 게임이 멈춘 뒤 종료됨.

### 정상 기대 흐름
1. 해금 가능한 개성 해금 칸 클릭
2. 즉시 가챠 시작
3. 결과 공개
4. 필요하면 재추첨
5. 별도 확정
6. 하단 확인/결정을 눌렀을 때만 순정 일러스트 + 장수 감사 대사
7. 원작 흐름으로 정상 복귀

## UI 수정
- 해금 1/2/3칸은 그대로 유지
- 2번째 칸을 재추첨으로 쓰지 않음
- 3번째 칸을 확정으로 쓰지 않음
- 재추첨/확정은 상단 인원수 옆 별도 순정풍 버튼
- 개성 해금 칸 클릭 즉시 가챠 시작

## 해금 진행
- 처음부터 3칸 전부 오픈 금지
- 원래 공로/승진 보상 조건과 플래그를 그대로 따름

## 진단 UI
- 대상 무장 아래 [계산 근거 펼치기/접기]
- 유사 무장/가중치/성장예산/열기/이변/초월/Roll ID/계산시간 등을 표시
- 열람 자체가 RNG/재계산을 발생시키지 않음

## 결과 평가
로그 끝에 `평범 -> 무난 -> 의외 -> 대박 -> 파격 -> 충격` 6단계 평가를 표시하려는 사용자 아이디어가 있음.
수동 개성 티어표 없이 현재 후보 분포의 상대 가치/놀라움/공식 희소성/특수 사건을 조합하는 방향을 추천. 상세 초안은 CONTINUE_PROMPT_KO.txt 참조.
