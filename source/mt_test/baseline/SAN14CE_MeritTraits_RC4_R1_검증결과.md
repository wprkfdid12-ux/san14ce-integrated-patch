# 논공 개성 가챠 RC4 R1 — 제작·검증 결과

**다운로드 가능한 실제 설치 패키지입니다. Windows 실게임 검증 완료판은 아닙니다.**

## CP03에서 이어 완료한 부분

CP03 소스를 이어 수정했습니다. 게임 원본 실행파일과 이전 원작 Hover 소스를 대조하여 다음 연결을 추가했습니다.

- 저장: 실제 파일명·Steam 계정별 키, 두 세대 보조 저장, 원본 저장 전 INTENT/저장 후 COMMITTED 기록, 충돌·중단 복구, 불명확한 상태의 추측 복원 금지.
- 원작 UI: 라디오 버튼 입력, 기존 Hover의 개성 설명·수치, 실제 장수별 논공 일러스트/대사 복귀.
- 연출: 원작 UI 효과음, 1.2초 순환, 고점 최소 0.6초 스킵, 100ms 글자 펀치, 원작 버튼 RGBA 강조와 정확한 복원. 별도 입자 렌더러는 추가하지 않았습니다.
- 편집/신무장: 현재 고유전법·부모 정보를 읽어 스타/혈연에 반영. 공식 교사 데이터는 오염시키지 않습니다.
- AI: 원작 논공 후보 순회에서 시작부터 열린 해금권을 처리하고 중복 지급하지 않습니다.
- 배포: 실제 설치, 알려진 RC3 해시 기반 자동 백업/이전, 중단 복구, 직전 패치 복원, 세이브·보조 정보 동반 백업.

## 시뮬레이션

같은 C 엔진으로 공식 무장 1000명 × 3회, 고정 시드, 재추첨 없이 최종 수락하는 3000회 시뮬레이션을 실행했습니다.
황금 10회, 이변 3회(초월 포함), 초월 1회였습니다. 이 결과는 일반 실플레이 전체나 AI 재추첨의 장기 분포를 뜻하지 않습니다.
현재 수치를 최종 밸런스로 인증하지 않았으며, 중앙 파라미터에 유지했습니다.
계산 시간과 자세한 예시는 소스 묶음의 audit/rc4_simulation.json에 있습니다. Linux 계산시간이지 게임 FPS가 아닙니다.

## 확인하지 못한 부분

Windows 설치/제거/되돌리기 스크립트 직접 실행, 실제 Steam/게임의 저장·로드, DirectX 화면, 마우스 감각, 소리, 60FPS, 장기 AI 플레이는 이 환경에서 실행하지 못했습니다.
설치기는 사용자 PC에서 실제 DLL 로딩/내보내기 진입점 검사를 먼저 수행합니다. 게임 효과까지 검사하지는 않습니다.
제공된 데이터에서 공식 소유자 연결이 없는 DLC 황금 개성 39종은 임의로 추가하지 않았습니다.
신무장/편집 이름의 실시간 로그 문자열 연결은 하지 않았습니다. 공식 이름 또는 null과 정확한 ID를 기록합니다.
별도 파티클 엔진은 없고 원작 버튼 색·문자 확대·원작 사운드로 표현합니다.
알 수 없는 외부 후킹/Hover 버전 조합은 안전하게 중지합니다. 모든 모드 조합 호환을 보증하지 않습니다.

## 저장정보 및 복원

보조 정보는 로컬이며 Steam Cloud 자동 동기화 대상이라고 가정하면 안 됩니다.
세이브백업.cmd는 선택한 .s14와 로컬 보조 정보 전체를 ZIP으로 보존합니다. 임의로 전체 메타데이터를 덮어쓰면 다른 슬롯도 과거 상태로 바뀔 수 있습니다.
ROLLBACK.cmd는 패치 파일의 직전 상태를 복원합니다. 이미 획득한 개성이나 저장 진행도까지 롤백하지는 않습니다.

## 재현

별도 Source ZIP의 source/build.sh와 tests를 사용합니다. source/README_SOURCE.txt에 실행 순서가 있습니다.
원본 게임 EXE·전체 메모리 이미지·원본 세이브는 어느 배포 ZIP에도 포함하지 않았습니다.

## ZIP 재현 확인

실제 Source ZIP을 별도 폴더에 다시 풀어 DLL을 재빌드했습니다. 두 DLL의 SHA256이 배포본과 일치했고, DLL 실행 검사 198개 및 정적 검사 93개를 다시 통과했습니다. 원본 게임 실행 검증을 추가했다는 뜻은 아닙니다.
