R6 실게임 확인 — 이 파일은 확인할 항목이며 '실게임 통과 보고서'가 아닙니다.
기존 다른 채팅방 영상은 R6 결과가 아닙니다.

1. 조운: 아랫줄2 획득/총3 가능 상태에서 윗줄 첫칸만 새 추첨 가능.
   둘째/셋째는 추첨 금지. 윗줄 결과는 원작 내정과 같은 선택색이고 결정 활성화.
   해제 후 아랫줄 셋째 선택/결정도 정상적으로 정책 보상만 적용되는지 확인.
2. 숙련/노련/중진 각 상황에서 현재 두 줄 합계만큼 왼쪽부터 선택.
   이미 확정된 칸, 다른 줄 선택, 원작 자동/군사/내정 우선 이후도 같은 한도.
3. 조통과 조광을 함께 등록. 조통 추첨/재추첨 후 조광 첫 해금은 계속 가능.
   각각 다른 횟수로 재추첨해 개인5개 한도와 페이지 전환 후 잔여권을 확인.
4. 추첨 직후/연출 중/재추첨 후/꽝 설명 중에 뒤로와 ESC 각각 확인.
   경고 아니오: 결과와 권수 유지. 예: 결과 폐기, 사용권 유지, 비용/랭크 미적용.
   지도 복귀 후 잠시 진행하고 재입장. 멈춤/튕김/남은 클릭 영역이 없는지 확인.
5. 결정 취소/내정 선택으로 변경해도 취소된 가챠 결과가 실제 개성에 들어가지 않아야 함.
6. 개성9칸 장수의 교체: 결정 전 실제 개성 유지, 기존/새 개성 경고 확인.
   아니오에서 유지, 예에서 선택한 대상만 교체. 여러 교체는 각각 확인 후 한 번 확정.
7. 빠른 두 번 클릭, 누른 채 창 밖/다른 버튼으로 이동, Alt+Tab, ESC 길게 누르기.
   이중 재추첨/경고 자동 예/먹통이 없어야 함. 하단 뒤로·경고 예/아니오 모두 확인.
8. '계산 근거' 중앙, 선택과 글꼴 통일. 재추첨과 선택 높이·위치 일치.
   다른 해상도/창모드/전체화면에서도 겹침·작은 글자·클릭 위치 오차 확인.
9. 가챠 결과 개성에 마우스를 올려 기존 수치 설명이 뜨는지 확인.
   정보/목록/출진 프리셋 RC25에서 실제9칸과 X 표시, 기존 개성 설명 유지 확인.
10. 뒤로 예 후 저장·종료·로드. 폐기된 결과는 없고 사용한 개인권은 유지.
    결정 성공 결과는 재입장/로드로 다시 뽑히지 않아야 함.

검증 장비에서 Windows/게임/DirectX 실행은 못 했습니다. 튕김 발생 시
문제자료모으기.cmd와 가챠로그추출.cmd로 R6 로그를 모으고, 마지막 조작·무장·해상도를
알려주면 같은 수정본의 실제 근거로 다음 작업을 이어갈 수 있습니다.
