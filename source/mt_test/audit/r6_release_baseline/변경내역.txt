RC4-R6-NativeChoice — 우리 R5-SafeExit_Confirm의 증분 수정

- 원작 status0(비활성)/status1(선택 가능) 의미를 바로잡음.
- 원작 upper/lower getter와 입력/refresh를 이용해 공유 선택 한도·좌→우 규칙 유지.
- 가챠 성공 시 원작 선택 등록, 원작 내정과 동일한 Selected 상태/결정 활성화 경로 사용.
- 무장 ID 및 기회별 미리보기 분리. 자동 선택만 하고 미추첨인 보상은 확정 차단.
- 미확정 윗줄을 해제하고 내정을 고르면 내정 보상은 원작에서 확정, 가챠는 폐기.
- 상단 확정/나감 제거 상태 유지. 계산 근거 중앙 정렬 및 선택 글꼴/재추첨 높이 유지.
- 뒤로/ESC 경고 예: 결과 초기화, 개인 재추첨권 차감 유지, 원작 취소 한 번 호출.
- 실제 교체는 무장·기존 개성·새 개성별 예/아니오 확인 후 원작 결정 한 번 실행.
- callback을 안전한 state tick으로 전달. 무장/기회/결과 세대, 활성/표시/포커스 검사.
- native 입력 누락 시 게임 논리좌표의 같은 버튼 press/release만 보완. 중복 실행 방지.
- 내정으로 줄어든 마지막 가능한 윗줄 기회도 꽝 제외.
- 새 Resolver 선택 binding 검증. 두 R6 DLL을 함께 패키징.
- 원본DB/실제 능력치/저장 v3/공통DLL/Hover/확인된 RC25 연동 유지.
- 원작 버튼 handler와 렌더 기계코드를 실행하는 R6 전용 검사를 추가.

과거 문서는 audit/r5_release_baseline. 최신 규칙은 별도 R6 추가수정지시서.
