# RC4-R6-NativeChoice 검증 결과

우리 R5-SafeExit_Confirm를 이어 수정한 빌드입니다. **실제 DLL 실행 검사 418개, 패키지 정적 검사 146개를 통과했습니다. Windows 실게임 검증은 하지 않았습니다.**

| 검사 | 통과 수 | 확인 내용 |
|---|---:|---|
| R6 동작 | 149 | 원작 선택 한도/좌→우, 조운 아래2칸, 조통·조광 분리, 취소·교체 경고, 개인권 저장, 폰트·버튼 계약, 입력 중복/포커스/해제 |
| 기존 기능 호환 | 258 | 엔진·DB·꽝·열정·평가·AI, 저장 저널/복구, 실제 공통Core와 Hover/RC25 표시 연결 |
| Win64 스택 프로브 | 11 | 실제 PE 스택 탐색 기계코드와 보호 페이지 |
| 패키지 | 146 | 동일 소스 재빌드 해시, PE/내보내기/의존성, payload, 이전 버전 인식, 설치 스크립트 정적 검사 |

실행 명령은 `tests/run_r6.py --with-package`입니다. 모든 네 검사 프로그램이 exit 0으로 끝났습니다. 상세 항목은 `audit/r6_tests.json`, `audit/r6_compat_tests.json`, `audit/cp03_stack_tests.json`, `audit/r6_package_tests.json`에 보존했습니다. 과거 R2~R5 보고서 수를 이 결과에 더하지 않았습니다.

## 실제로 실행한 범위

최종 Win64 DLL을 Microsoft ABI 브리지로 실행했습니다. 보존된 원작 보상 버튼 처리(0x770080), 논공 state tick(0x732f50), 보상 렌더 분기(0x8a2fdc..0x8a3217), 종료 가드(0x6be850) 기계코드도 실행했습니다. 공통Core의 실제 후킹 등록 코드와 제공 RC25의 개성9칸 렌더 코드도 검사했습니다.

원작 상태 조회/카운트 getter/UI refresh, OS/Steam, 위젯 생성, 비용 처리, 페이드 종료는 대체 접점입니다. 실제 원작 렌더 분기에서 상태0이 비활성이고 상태1의 선택색은 별도 카운트로 결정됨을 확인한 뒤 R6 fixture에 반영했습니다. 이전 UI fixture의 잘못된 상태 해석은 현재 검사의 기준으로 사용하지 않습니다.

## 수정 효과를 확인한 주요 사례

- 아래2칸을 얻은 조운: 위 첫칸만 추가 추첨, 원작 선택 기록과 선택색/결정 조건 연결. 위 둘째·셋째와 추가 내정 선택은 차단.
- 모든 현재 한도1/2/3과 가능한 내정 선행 조합: 각 줄 좌→우 및 합계 한도 유지.
- 가챠 해제 후 내정 선택: 내정은 원작에서 확정하고, 미확정 가챠 효과는 폐기.
- 조통·조광: 결과/권수 분리, 이전 무장 callback 거부, 5개 소진 후 추가 차감 없음.
- 뒤로/ESC: 연출·결과·재추첨·꽝 상황에서 예/아니오. 예는 결과만 폐기, 비용/랭크/개성/X/열정 적용 없음. 권수는 저장·로드 후 유지.
- 가득 찬 개성칸 교체: 기존/새 개성 확인, 아니오에서는 원래 개성 유지. 여러 교체는 각각 동의한 뒤 원작 확정 한 번.
- 경고 할당 실패, 소유 row 해제, 강제 화면 이탈, 빠른/지연 callback, 다른 화면 겹침, 포커스 이탈: 임의 동의·이중 실행 방지.
- 원본DB 비교와 현재 편집 능력치 보존, 기존 Hover 설명 연결, 취소로 열정/X를 획득하지 않는 동작 유지.

## 변경하지 않은 구성

공통 Loader/Core/기본Resolver/Hover payload 해시와 저장 v3/표시 연결 소스의 보존을 검사했습니다. R6에서 바뀐 전용 Resolver와 기능DLL은 반드시 함께 설치합니다. 설치 대상은 기존 8개 허용 경로로 한정하며 알 수 없는 다른 모드 파일을 덮어쓰지 않습니다.

## 한계와 다음 확인

Windows 설치기 실행, 실제 게임 UI 렌더/포커스/입력 루프, 화면 전환 후 수명, 소리와 FPS는 확인 전입니다. 원작 busy 종료 가드는 유지하며 알 수 없는 필드를 강제로 지우지 않습니다. 다른 채팅방의 영상/로그는 참고 사례일 뿐 이 빌드를 플레이한 자료가 아닙니다. 따라서 무조건 안 튕긴다는 보장은 하지 않습니다.

실게임 확인 순서는 `실게임확인.txt`입니다. 원작 X 아이콘 리소스는 아직 식별하지 못해 원작 글자 X를 사용합니다. 확인된 Hover/RC25 이외의 독자 패널에는 별도의 연동 확인이 필요합니다.

교체 추가 검사에서는 callback revision이 그대로인 상태에서 원작 선택 기록만 바꿨습니다. 최종 교체 목록이 달라지면 기존 동의를 거부하고 다시 확인한 뒤 현재 선택한 교체만 적용하는 것을 확인했습니다.
