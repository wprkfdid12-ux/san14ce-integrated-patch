삼국지14 CE 한국어판 — 논공 개성 가챠 RC4-R6-NativeChoice
우리 R5-SafeExit_Confirm를 이어 수정한 설치용 후보입니다.

설치
1. 게임 종료 후 세이브백업.cmd로 원본 세이브와 보조정보를 함께 백업합니다.
2. Install ZIP 전체를 압축 해제하고 INSTALL.cmd를 실행합니다.
3. 자동으로 찾지 못하면 SAN14CE_KO.exe를 선택합니다. INI/주소 편집은 없습니다.
검증된 이전 파일만 업그레이드합니다. 알 수 없는 타 패치는 덮어쓰지 않습니다.
ROLLBACK.cmd는 직전 패치 복원, UNINSTALL.cmd는 관리한 논공 파일 제거/복원입니다.
R6 기능 DLL과 R6 전용 Resolver를 한 쌍으로 설치하세요. 설치기가 함께 처리합니다.

선택 방법
윗줄 지휘 보상만 개성으로 바뀌며 두 줄의 선택 규칙은 원작과 같습니다.
각 줄은 왼쪽부터, 두 줄 합계는 현재 랭크 한도(최대3)입니다.
아랫줄2칸을 이미 얻은 조운은 윗줄 첫칸 또는 아랫줄 셋째 중 하나만 더 고릅니다.
개성 해금 추첨이 성공하면 원작 선택 색상으로 표시합니다.
다시 누르면 원작처럼 선택 해제/재선택하며 같은 결과를 유지합니다.
필요한 선택을 채운 뒤 하단 결정으로 실제 적용합니다. 상단 확정/나감은 없습니다.
가득 찬 개성칸 교체는 결정 뒤 기존/새 개성을 보여주는 예·아니오 확인을 거칩니다.
여러 교체를 선택했다면 각각 예로 확인한 뒤 한 번 반영합니다.

뒤로가기 규칙 — R5에서 변경됨
미확정 추첨 결과가 있으면 뒤로/ESC에서 예·아니오 경고를 띄웁니다.
예: 뽑아 놓은 미확정 결과와 임시 보상 선택을 초기화하고 나갑니다.
    사용한 재추첨권은 복구하지 않습니다. 논공 비용·랭크·개성·X·열정은 적용하지 않습니다.
아니오: 현재 결과/선택/개인권 그대로 돌아갑니다.
이미 결정으로 얻은 보상은 유지됩니다. 경고 안의 새 ESC는 아니오입니다.
아직 추첨 전 승계 선택만 했다면 정상 취소합니다.
장수1명당 전체 기회에서 재추첨권 총5개입니다. 장수·페이지 사이에서 공유하지 않습니다.

화면/기존 기능
'계산 근거'는 버튼 중앙, 선택과 같은 글꼴. 재추첨도 선택 높이·위치·글꼴을 따릅니다.
경고는 게임 패널/버튼 리소스를 사용합니다. 설명창 확인은 효과를 확정하지 않습니다.
실제 개성 설명은 기존 Hover로 표시합니다. X에는 가짜 개성 설명이 없습니다.
꽝은 결정으로 확정했을 때만 X/다음 기회 열정 적용. 실제9칸 꽝은 기존 개성 유지.
내정 때문에 마지막 가능한 개성 기회가 첫째/둘째가 된 경우도 마지막은 꽝 제외입니다.
공식 대상과 비교 무장 모두 DB 원본 능력치 분포 기준입니다. 편집/성장은 건드리지 않습니다.

저장
미확정 결과가 있으면 저장을 막습니다. 결정 또는 뒤로 취소를 마친 후 저장하세요.
취소 후 저장한 개인 재추첨권 사용량은 다시 로드해도 그대로입니다.
원본 .s14와 %LOCALAPPDATA%\SAN14CE_MeritTraits\CEKO_6a6d9f72를 함께 보관하세요.
보조정보는 Steam Cloud 자동 동기화 대상이 아닙니다. 이전 세이브 반복 로드는 막지 않습니다.
R3/R4/R5와 같은 v3 형식입니다. R2 이하로 복원 시 해당 버전과 맞는 세이브 백업도 필요합니다.

DLL 실행/원작 코드 분기/호환/패키지 자동 검사 결과는 검증결과.md에 있습니다.
실제 Windows 게임 실행과 종료 튕김 해소는 아직 확인 전입니다.
