# 논공 개성 가챠 RC4 R3 — 검증 결과

제공된 R2를 이어 수정한 설치 후보입니다. **실게임 검증 완료판은 아닙니다.**
추가수정지시서는 기존 제안서에 합치지 않고 원문을 별도로 보존했습니다.

## 구현한 변경

- 추첨/재추첨 후 나감·ESC를 원작 취소 버튼 동작에 연결. 안전tick에서 종료 처리.
- 결과를 잡고 있는 동안에도 기존 개성 Hover를 갱신. 비활성 버튼의 부모 hit target 지원.
- 실제 개성 설명은 기존 Hover에 실제ID를 전달. 별도 설명 데이터베이스 없음.
- 장수1명마다 개인 재추첨권5개. 그 장수의 세 기회 안에서만 공유.
- 꽝 별도 결과, 빈 실제 위치를 sidecar X로 점유. 실제9/9는 개성을 건드리지 않음.
- 별도 확정+원래 하단 결정 때만 X·열정 반영. 취소·재추첨한 꽝에는 둘 다 없음.
- 다음 기회의 열정: 꽝 방지, 적합도/황금 후보 가중치 증가, 재추첨·취소·저장/로드 유지.
- 세 번째 물리칸과 시간순 마지막 기회는 꽝 제외. 꽝은 6단계 평가·효과에서 제외.
- 꽝 안내는1200ms 연출 후 안전tick에서 한 번. 안내 닫기/뒤쪽 입력이 자동commit하지 않음.
- 저장v3는 기존 struct 크기/두 세대 저널 유지. v2 결과와 무장별 재추첨 이력을 그대로 이관.
- 외부 편집이 X 자리를 실제 개성으로 채우면 실제 개성 우선, 해당 X만 제거.
- 기존 DB 원본 능력치 비교 유지. 편집·성장한 실제 게임 능력치는 덮어쓰지 않음.

예전 R1/R2 보고서는 이 통과 수에 중복 산입하지 않았습니다.

## 재현한 경계

일반 추첨 후 종료, 재추첨 후 종료, ESC, 꽝 안내 전/후 취소, 별도 확정 후 취소,
다른 무장으로 이동하며 개인권 차감, 모달 위의 재추첨/확정/하단결정 차단,
같은 Roll ID의 재추첨 후 새 꽝 안내, row 파괴 후 stale callback, 원작 취소 어댑터 실패 시 요청 해제,
하단결정 뒤늦은 자동commit 방지, 일부 Hover hook 설치 실패 시 전체 새 연결 rollback을 검사했습니다.

저장에서는 확정된 꽝/X/열정, 다음 기회 취소 후 버프 유지, 장수별 재추첨권과 취소한 사용량,
v2 ignored-padding의 기본값 이관, 과거 결과/디스크 bytes 보존, 새v3 저장을 검사했습니다.
공식 조광의 실제 능력치를99/98/97/96/95로 바꾸어도 비교 입력65/68/53/51/60은 같고,
가챠 확정 후 실제 능력치는 편집값 그대로인지 기존 R2 검사를 다시 통과했습니다.

## 패키지와 기존 패치

공용 dxgi/Core/기본 Resolver/Hover 파일4개는 기존 제공본과 동일합니다.
기존 논공 hooks34개와 native adapters27개를 유지하고, 정확한 Hover 해시에 별도 display bridge7개를 추가했습니다.
실행 검사한 DLL과 설치 payload의 SHA256 일치 및 같은 소스의 결정적 재빌드를 검사했습니다.
R2/R1/RC3의 정확한 해시만 업그레이드 대상으로 허용합니다. 알 수 없는 파일은 덮어쓰지 않습니다.
다른 패치의 설명을 자체 문구로 대체하거나 게임의 실제 개성 getter를 가짜ID로 변경하지 않습니다.
세부 연결 위치는 analysis/hover_x_contract.md에 있습니다.

## 초기 확률과 시뮬레이션

꽝 기본값5%, 열정 적합도 문턱0.5, 적합도 가중치1.35배, 황금 가중치1.5배입니다.
모두 source/gacha.c의 g_params에 있으며 최종 밸런스 인증값은 아닙니다.
기존 열기와 별개이며 6단계 평가는 사후 설명만 합니다.
같은 C 엔진을 Linux용으로 빌드한 공식1000명×3회 고정시드 시뮬레이션에서
3000회 중 꽝81회, 다음 기회 열정 적용81회를 관찰했습니다.
마지막칸/열정 보호를 포함한 전체 관측치이므로 전체 꽝률이 기본5%와 같아야 하는 검사는 아닙니다.
세부 결과는 audit/r3_simulation.json이며 계산 시간은 게임FPS나 실플레이 장기 분포가 아닙니다.

## 미완료 및 실게임 확인 필요

1. 실제 Windows에서 먹통 재현 해소, 가챠 결과 Hover, 원래 하단 결정 후 대사·복귀1회 확인.
2. X는 현재 원작 글자 렌더러의 X입니다. 원작 X 아이콘 리소스 재사용과 실제 폰트 표시 검증은 미완료입니다.
   적절한 원작 X 아이콘이 없다고 검증한 것이 아닙니다.
3. 기존 Hover의 공통 정보창·collector·무장/기본무장/부대 목록 경로에 X를 연결했습니다.
   다른 패치가 독자적으로 만든 전용 UI 전체의 연결은 미완료입니다.
   SAN14_MeritSlotDisplayV1을 제공하지만 그 API를 상대 패치가 호출해야 전용 화면도 표시할 수 있습니다.
4. X의 고정 Hover 안내는 생략했습니다(지시서 허용 분기). 실제 개성 Hover만 기존 설명 엔진을 사용합니다.
5. 모든 실화면의 X 위치, 해상도·스크롤·무장전환·모달 입력 우선순위와 자원 수명을 확인해야 합니다.
6. Windows 설치/롤백/제거 스크립트 실행, 실제 Steam 저장/로드, DirectX·음향·60FPS는 미검증입니다.
7. 보조정보는 Steam Cloud 자동 동기화 대상이 아니며 매핑 미확인 DLC 황금39종은 후보에 추가하지 않았습니다.
