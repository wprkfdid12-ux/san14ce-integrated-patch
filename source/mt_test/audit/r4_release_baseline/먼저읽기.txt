삼국지14 CE 한국어판 — 논공 개성 가챠 RC4 R4 설치 후보
가장 최근 R3 작업을 그대로 이어 수정했습니다.

설치
1. 게임을 종료하고 세이브백업.cmd로 원본 세이브와 보조정보를 함께 백업하세요.
2. ZIP 전체를 압축 해제하고 INSTALL.cmd를 더블클릭하세요.
3. 자동으로 못 찾으면 SAN14CE_KO.exe를 선택합니다. INI·주소·명령어 편집은 필요 없습니다.
알려진 R3/R2/R1/RC3 파일만 해시 확인 후 백업·갱신합니다. 알 수 없는 패치는 덮어쓰지 않습니다.
공용 dxgi/Core/기본 Resolver/Hover DLL 파일은 이전 제공본과 같습니다.

이번 수정
- 실제 공용 로더에서 기존 Hover 연동 등록이 거절될 수 있던 오류를 수정했습니다.
  공용 로더 파일은 그대로 두고, DLL 내부 표시 연결과 게임 본체 연결을 분리했습니다.
- X가 있는 정보창에서 실제 붉은 개성도 원래 이름·색으로 보이도록 수정했습니다.
- 제공된 출진 프리셋 RC25의 전용9칸에도 X 표시를 연결했습니다. 프리셋 DLL 파일은 교체하지 않습니다.
  정확히 같은 버전일 때만 연결하며 실제 개성 설명·프리셋 입력은 원래 코드를 유지합니다.
- 다른 패치가 표시 API를 너무 일찍 호출해도 안전하게 원래 표시로 돌아갈 수 있도록 보완했습니다.
- 기존 확률·장수별 재추첨권·능력치 비교·저장 형식은 R3 그대로입니다.

유지되는 R3 기능
- 가챠 결과에 마우스를 올리면 기존 개성 Hover 엔진에 연결해 원래 설명을 요청합니다.
- 추첨·재추첨 후 나감/ESC가 원작 취소 동작으로 빠져나가도록 수정했습니다.
- 각 장수마다 개인 재추첨권 총5개. 그 장수의 세 논공 기회에서만 공유합니다.
  다른 장수·페이지의 횟수는 차감하지 않습니다. 취소해도 이미 사용한 재추첨권은 복구되지 않습니다.
- 낮은 확률의 꽝(초기값5%) 추가. 마지막 물리칸과 시간순 마지막 기회에는 꽝이 없습니다.
- 꽝은 안내창을 닫았다고 확정되지 않습니다. 별도 [확정]과 원래 하단 [결정]이 모두 필요합니다.
- 최종 확정한 꽝만 빈 개성칸을 X로 소모하고 해당 무장에게 열정 버프를 줍니다.
  재추첨·취소한 꽝은 X/버프를 만들지 않습니다. 실제 개성9개가 있으면 기존 개성은 그대로 둡니다.
- 열정은 다음 논공 기회에서 꽝을 막고 좋은 적합도·황금 후보의 가중치를 올립니다.
  재추첨·취소·저장/로드에도 유지되며 실제 개성을 최종 반영할 때만 소모합니다.
- X는 표시·점유정보뿐입니다. 실제 개성 효과·중복판정·6단계 평가에는 포함하지 않습니다.
  사실무장 편집 등으로 X 위치에 실제 개성이 들어오면 그 X만 사라집니다.

논공 조작
사용 가능한 해금칸 클릭 → 추첨 → 별도 [재추첨]/[확정] → 원래 하단 [결정]으로 최종 반영.
완료칸을 다시 눌러도 감사 대사나 종료를 중복 실행하지 않습니다.
[나감]/ESC는 미반영 선택을 취소합니다. 꽝 안내창 안의 ESC/Enter는 안내창만 닫습니다.
일반 연출은 Enter 또는 [건너뛰기]로 넘길 수 있습니다. 고점은 최소0.6초, 꽝은1.2초 유지합니다.
일반 무장9/9의 승계 선택, 스타9/9의 결과 후 교체/포기 흐름은 R2대로 유지합니다.
[계산 근거 펼치기]에는 비교 입력·후보·개인 재추첨·열정·점유 슬롯 등을 표시합니다.
꽝은 6단계 평가가 없습니다. 평범~충격 평가는 설명용이며 추첨 확률의 입력이 아닙니다.

능력치 기준
공식 대상 장수와 비교 장수 모두 원래 DB 능력치 분포를 사용합니다. 능력치 합계 판정이 아닙니다.
조광 비교 입력: 통65/무68/지53/정51/매60. 실제 게임의 편집·성장 능력치는 건드리지 않습니다.
원본 DB 없는 신무장만 현재 기본값을 사용합니다. 보유 개성·고유전법·부모는 게임 현재값입니다.

저장·복원 주의
하단 결정 전 선택이 남으면 저장을 막습니다. 취소하거나 하단 결정을 마치고 저장하세요.
이미 저장된 확정 결과는 로드로 바뀌지 않습니다. 미추첨 상태에서 로드 후 새 추첨은 달라질 수 있습니다.
원본 .s14와 %LOCALAPPDATA%\SAN14CE_MeritTraits\CEKO_6a6d9f72 보조정보가 함께 필요합니다.
보조정보는 Steam Cloud 자동 동기화 대상이 아닙니다.
ROLLBACK.cmd는 직전 패치 파일 복원, UNINSTALL.cmd는 관리한 논공 파일 제거/복원입니다.
R3 저장 후 R2로 되돌리면 R2가 새 보조정보를 읽지 못합니다. 설치 전 대응 세이브 백업도 함께 필요합니다.
R4는 R3와 저장 형식이 같습니다. R2 이하로 돌아갈 때의 위 제한은 그대로 적용됩니다.
보조정보만 지워 맞추지 마세요. 문제자료모으기.cmd / 가챠로그추출.cmd는 자료 수집만 하며 자동 전송하지 않습니다.

확인된 범위와 아직 남은 부분
DLL 실행 assertion411개와 패키지 정적 assertion135개 통과. 실제 Windows 게임은 미검증입니다.
먹통과 호버 문제의 코드 경로는 수정했지만, 실게임에서 재현 해소를 확인한 완료판이라고 보장하지 않습니다.
X는 현재 원작 글자 렌더러를 사용합니다. 원작 X 아이콘 재사용과 실제 글자 표시 확인은 아직 남았습니다.
기존 Hover 공통 정보창/목록과 제공된 정확한 RC25 전용창에 X 표시를 연결했습니다.
그 외 다른 버전·독자 화면까지 자동 호환되는 것은 아닙니다. RC25 연결 실패는 논공 활성화를 막지 않습니다.
X 자체의 Hover 설명은 생략합니다. 실제 개성은 기존 Hover를 그대로 사용합니다.
정확한 Hover 버전이 아니거나 알 수 없는 충돌이 있으면 덮어쓰지 않고 가챠 활성화를 거부합니다.
실게임 첫 확인은 별도 세이브에서 진행해 주세요. 자세한 검증 범위는 검증결과.md에 있습니다.
