# R4 이어갈 지점

가장 최근 R3 전달본에서 이어 수정했습니다. CONTINUE_PROMPT_KO.txt가 현재 인계 기준입니다.
추가수정지시서 원문은 references/proposals에 별도 보존했습니다.

가장 최근 요청은 재추첨 여부와 무관하게 가챠 후 먹통 방지, 기존 개성 설명 Hover 및 다른 패치 연동입니다.
원작 취소 버튼 호출과 기존 Hover 호출 경로를 수정하고 DLL 회귀 검사를 추가했습니다.
R4에서는 X 옆의 붉은 개성 누락, 너무 이른 표시 API 호출을 보완하고,
제공된 정확한 출진 프리셋 RC25의 전용9칸도 표시 전용 bridge로 연결했습니다.
실제 Core가 게임 주소만 받는데 R3가 Hover DLL 주소를 넘기던 초기화 오류도 발견·수정했습니다.
공용 Core를 바꾸지 않고 DLL 내부 연결을 분리했으며, 실제 Core의 등록 코드를 실행해 검증했습니다.
그 외 버전이나 다른 독자 UI는 아직 별도 연결/검증이 필요합니다.
원작 X 아이콘 재사용도 미완료이며 지금은 원작 글자 렌더러를 통한 X입니다.
실게임 확인 없이 모든 화면·모든 패치 호환이나 먹통 완전 해소를 보장하지 마세요.

검증: 실제 Win64 DLL + 대체 OS/게임 접점411개, 별도 패키지 정적135개. Windows 실게임은 미검증입니다.
R3 엔진/상태/개인권/입력/저장/공식DB 파일은 해시 동일. audit/R3_to_R4.diff를 확인하고 이어가세요.
