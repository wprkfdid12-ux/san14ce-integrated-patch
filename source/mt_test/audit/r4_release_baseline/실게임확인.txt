RC4 R4 설치 후보 — 실제 게임에서 남은 확인 순서

자동 검사를 통과했어도 아래 항목의 Windows/게임 화면 검증을 대신하지는 않습니다.
원래 진행 세이브를 덮어쓰지 말고, 게임 종료 후 세이브백업.cmd로 원본+보조정보를 함께 백업하세요.
압축을 풀고 INSTALL.cmd를 실행한 뒤 별도 테스트 세이브에서 확인하세요.

1. 기존 R3에서 이어 플레이 가능한지, 논공 버튼이 정상 표시되는지 확인.
2. 일반 추첨 직후 결과 위에 마우스를 올려 기존 개성 설명이 표시되는지 확인.
3. 재추첨하지 않고 [나감]/ESC로 화면에서 나올 수 있는지 확인.
4. 다시 추첨→재추첨 후 설명이 새 개성과 맞는지, [나감]/ESC가 동작하는지 확인.
5. 무장 A에서 사용한 재추첨권이 무장 B의5개를 줄이지 않는지 페이지를 바꿔 확인.
6. 별도 [확정] 뒤 원래 하단 [결정]으로 결과가 한 번만 적용되고 정상 복귀하는지 확인.
7. 자연스럽게 꽝이 나왔을 때: 안내를 닫는 것만으로 X/열정이 적용되지 않아야 함.
   최종 결정한 꽝만 X/열정을 남기고, 재추첨·취소한 꽝은 남기지 않아야 함.
8. X가 생긴 장수의 정보창·무장/부대 목록에서 물리칸 위치와 붉은 개성 보존 확인.
9. 제공된 정확한 출진 프리셋 RC25를 함께 쓴다면: 같은 장수를 선택해 X 위치 확인.
   다른 장수로 전환하면 이전 장수의 X가 남지 않아야 하며 실제 개성 호버는 원래 설명이어야 함.
   프리셋 닫기, 선택, 확인창 입력이 정상인지도 확인. 다른 버전은 자동 연결 대상이 아님.
10. 테스트 결과를 별도 슬롯에 저장·로드해 확정된 개성/X/열정/장수별 재추첨 횟수 확인.

X는 현재 원작 글자 렌더러의 X입니다. 원작 X 아이콘 리소스 식별·재사용은 남은 작업입니다.
모든 다른 패치의 독자 화면까지 자동 연결했다는 뜻은 아닙니다.
문제 발생 시 문제자료모으기.cmd / 가챠로그추출.cmd로 자료를 모을 수 있습니다.
자료는 자동 전송되지 않습니다. 발생 화면과 조작 순서를 함께 전달하면 다음 작업을 이어갈 수 있습니다.
보조 저장정보만 삭제해 맞추지 마세요. R2 이하로 내려가려면 대응하는 pre-R3 백업도 필요합니다.
