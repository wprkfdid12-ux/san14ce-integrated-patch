# 현재 작업 기준 — RC4-R5-SafeExit

이 대화에서 이어 온 R4 기반 수정본을 기준으로 점검한다. 재시작하지 않는다.
다른 채팅방 버전의 영상/로그는 예방 점검의 참고 사례이며 우리 수정본의 실게임 재현이 아니다.
그 버전의 소스를 병합하지 않았다.

현재 최우선 요구는 무장별 입력/상태 분리, 종료 뒤 튕김 위험 점검,
뒤로/ESC의 마지막 결과 확정, 개인 재추첨권 복구 금지, 상단 확정/나감 제거다.
최신 추가에 따라 뒤로/ESC는 예/아니오 경고를 먼저 표시한다. 예만 확정/종료하고
아니오는 결과/남은 개인권을 유지한다. 경고는 원작 스킨/선택 글꼴, 숨은 입력과 늦은 동의 차단.
계산 근거 한 줄 중앙, 재추첨은 선택 버튼 기준 높이/글꼴.
원본DB 능력치 비교, 실제 능력치 보존, 기존 Hover 및 다른 패치 연동을 유지한다.

최신 규칙은 CONTINUE_PROMPT_KO.txt와 별도 추가수정지시서가 우선한다.
예전 제안서를 다시 합치거나 예전 '취소하면 버림' 동작으로 되돌리지 않는다.
아직 추첨 전 승계 선택은 정상 취소. 스타9칸 교체 미선택은 기존 개성 보존.
강제 world/layout 해제는 안전상 소멸 중 commit하지 않으며 사용한 개인권만 보존.
