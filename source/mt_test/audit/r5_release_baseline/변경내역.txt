RC4-R5-SafeExit — R4 증분 수정

- 상단 확정/나감 객체와 클릭 영역 제거.
- 계산 근거 한 줄 중앙 정렬. 재추첨 높이/글꼴을 원작 선택 기준으로 변경.
- 조통 결과가 있어도 조광 해금 입력 가능. 무장별 pending/교체 선택/개인권 분리.
- 성공한 개인 재추첨권 즉시 예약 차감, 취소로 복구되지 않게 처리.
- 뒤로/ESC는 개성 확정/개인권 복구 없음 경고(예/아니오)를 먼저 표시.
  예만 원작 결정 절차로 마지막 결과 반영/종료. 아니오는 현재 결과/개인권 그대로 복귀.
- 원작 패널/버튼 스킨, 선택 글꼴, 본문 고유 글자색 유지. 별도 OS 모달 없음.
- 누르고 있던 입력/연속 클릭/이전 경고 콜백/숨은 결정 요청/생성 실패에 의한 자동 동의 차단.
- 바깥 논공 화면과 안쪽 무장 목록을 구별해 상태 조회 오류 수정.
- 해제 전 callback 무효화, 재진입 차단, 행 갱신/소멸 전 연출 포인터 정리.
- 실패한 결정 요청의 매 프레임 반복 차단. 원작 비용 실패 때 결과를 새로 뽑지 않음.
- 꽝 안내도 최신 뒤로 확정 규칙으로 변경.
- 다른 채팅방 버전의 영상/로그를 참고해 우리 수정본의 입력/해제/콜백 회귀 검사 추가.
- 이벤트 버전 표시와 종료 단계별 진단 기록 추가.
- 확인된 R4/다른 R5 정확한 파일 해시만 업그레이드 허용.

유지: 확률/평가 엔진, 원본DB, 능력치 편집/성장, MISS/X/열정,
개인5권, 저장v3, 공통 Hover, R4 Core/RC25 호환 수정, 다른 패치 파일.
검증 범위/실게임 미확인 사항은 검증결과.md 참고.
