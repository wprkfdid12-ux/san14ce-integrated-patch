이번 수정
- Preview는 무장ID별, native_owner(안쪽 목록)와 stage별 replacement 별도 보관.
- 다른 무장으로 이동해도 pending 결과 보존. 같은 무장의 다음 기회로 넘어갈 때만
  이전 결과를 그 무장 미리보기 안에서 수락하여 예산/열기/열정 순서 유지.
- prepare_previews는 복사본을 먼저 검증. 실제 반영은 원작 결정 성공 후.
- F_STATUS에 바깥 화면이 아닌 원래 row의 안쪽 부모 전달. 기존 평평한 모의 화면이
  이 오류를 숨겼으므로 R5 검사는 실제처럼 두 객체를 나눔.
- 뒤로 callback은 요청만 기록. 안전한 state tick에서 원작 결정 요청1을 한 번 실행.
  같은 종료에 원작 cancel과 결정/pop을 중복하지 않음. 실패한 결정의 무한 재시도 차단.
- unregister 전에 callback 세대 무효화. 해제 중 재진입/재등록 차단.
  원본 row refresh/destruct 전에 연출 포인터 복원. visible 목록에서 먼저 제거.
  원작 resource_context를 보존하며 소유 버튼을 한 번씩 해제.
- unregister와 실제 resource destroy를 혼동하지 말 것.
- 이벤트/활성화 로그를 RC4-R5-SafeExit로 표시. 종료 단계별 runtime 기록 추가.
- 경고는 안전 tick에 생성/해제. 원작 패널/버튼 스킨과 선택 글꼴 사용.
  본문은 패널 고유 글자색을 보존해 버튼의 짙은 글자가 어두운 배경에 묻히지 않게 함.
  누르고 있던 입력은 동의가 아님. 경고 뒤 결정/선택 요청 제거, 가로챈 ESC 입력 소비.
  경고 세대별 callback 검증, 첫 예/아니오만 처리. 아니오에서 연출 시간도 보존.
  생성 실패는 절대 예로 처리하지 않음. 결과/권수 유지, 새 뒤로 요청으로 재시도 가능.
  원작 결정은 별도로 가능. 위젯별 등록 상태를 추적해 일부 생성 실패/해제 중 중복 방지.
