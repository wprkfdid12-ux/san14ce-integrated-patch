삼국지14 CE 한국어판 — 논공 개성 가챠 RC4-R5-SafeExit 수정 후보
기존 R4를 이어 수정했습니다. 다른 채팅방의 RC4-R5와 구분되는 버전입니다.

설치
1. 게임을 완전히 종료하고 세이브백업.cmd로 원본 세이브/보조정보를 함께 백업합니다.
2. Install ZIP 전체를 압축 해제하고 INSTALL.cmd를 실행합니다.
3. 자동으로 못 찾으면 SAN14CE_KO.exe를 선택합니다. INI/주소 편집은 필요 없습니다.
확인된 R4/다른 R5 등 정확한 파일만 업그레이드합니다. 알 수 없는 수정 파일은 덮어쓰지 않습니다.
설치가 거부되면 메시지를 보내주세요. 다른 패치 파일을 강제로 지우지 마세요.
공용 로더/Core/기본Resolver/Hover는 원래 바이트를 유지합니다.

바뀐 사용법 — 중요
상단 확정/나감은 없습니다. 개성 해금→결과→필요하면 재추첨→하단 결정 또는 뒤로/ESC.
추첨 후 뒤로/ESC는 '개성이 확정되고 재추첨권은 복구되지 않는다'는 예/아니오 경고를 띄웁니다.
예: 마지막 결과를 확정하고 종료. 아니오: 현재 결과와 남은 개인권 그대로 화면으로 복귀.
경고창 안에서 새로 누르는 ESC는 아니오입니다. Enter만으로 자동 동의하지 않습니다.
일반 확정은 원래 하단 결정 버튼으로 합니다. 상단 확정은 없습니다.
개성/꽝/열정과 논공 비용은 원작 결정이 성공할 때 한 번 반영됩니다.
성공한 재추첨권은 즉시 해당 장수에게만 차감되며 취소로 돌아오지 않습니다.
장수1명당 자신의 세 번의 논공 기회 전체에서 개인 재추첨권 총5개입니다.
아직 추첨하지 않은 승계 선택에서 뒤로/ESC는 보상/비용 없이 정상 취소합니다.
꽝 안내의 확인은 설명만 닫습니다. 뒤로/ESC 경고의 예는 꽝도 확정하므로 X/다음 기회 열정을 받습니다.
실제9칸 꽝은 기존 개성을 지우지 않습니다. 스타9칸의 교체 대상을 고르지 않았다면
기존 획득 포기 규칙대로 기존 개성을 보존합니다. 임의 교체는 하지 않습니다.

무장/버튼
조통 결과 후 조광 해금을 누를 수 있고, 조통 결과를 다시 눌러 개인 재추첨을 이어갑니다.
같은 장수의 다음 기회를 시작하면 이전 결과는 미리보기 안에서 선택 완료됩니다.
실제 반영은 결정/뒤로입니다. 장수끼리 결과·개인권을 섞지 않습니다.
계산 버튼은 '계산 근거' 한 줄 정중앙. 재추첨/경고의 예·아니오 글꼴도 선택과 맞췄습니다.
경고는 게임 패널/버튼 모양과 고유 색을 사용합니다. 별도 윈도우 창을 띄우지 않습니다.
가챠 실제 개성 설명은 기존 Hover를 사용합니다. X에 가짜 개성 설명은 붙이지 않습니다.

기존 규칙/저장
공식 대상과 비교 무장 모두 원본 DB 능력치 분포 기준. 편집/성장 능력치는 건드리지 않습니다.
원본 없는 신무장만 현재 기본값 사용. 보유 개성/부모/고유전법은 게임 값입니다.
미반영 결과가 남으면 저장을 막습니다. 결정/뒤로 반영을 마치고 저장하세요.
세이브로드 반복 방지는 추가하지 않았습니다. 저장한 확정 결과는 다시 뽑지 않습니다.
원본 .s14와 %LOCALAPPDATA%\SAN14CE_MeritTraits\CEKO_6a6d9f72 보조정보를 함께 보관하세요.
보조정보는 Steam Cloud 자동 동기화 대상이 아닙니다. 보조정보만 지워 맞추지 마세요.
R3/R4와 같은 v3 저장 형식입니다. R2 이하로 복원하려면 대응하는 설치 전 세이브 백업도 필요합니다.
ROLLBACK.cmd는 직전 패치 복원, UNINSTALL.cmd는 관리한 논공 파일 제거/복원용입니다.

확인 범위
검증결과.md의 자동 검사를 통과했지만 실제 Windows 게임에서는 아직 확인 전입니다.
다른 채팅방 영상/로그를 참고해 우리 수정본을 점검했으나 무조건 안 튕긴다고 보장하지 않습니다.
별도 테스트 세이브로 실게임확인.txt의 조통·조광→재추첨→뒤로 순서를 먼저 확인해 주세요.
문제가 남으면 가챠로그추출.cmd 또는 문제자료모으기.cmd로 기록을 모으세요. 자동 전송은 없습니다.
새 runtime 기록은 R5-SafeExit의 EXIT_WARNING_SHOWN/EXIT_YES/EXIT_NO와 기존 종료 단계입니다.
경고 생성에 실패하면 임의로 확정하지 않습니다. 결과/개인권은 그대로이며 하단 결정은 가능합니다.
X는 현재 원작 글자 렌더러의 X. 원작 아이콘 재사용은 미완료입니다.
정확한 제공 Hover/출진 프리셋 RC25 연결 유지. 모든 독자 패치 화면 자동 호환은 보장하지 않습니다.
