R11 실제 수정 내역 — 2026-09-21

[1] 마등 논공 후 화면 멈춤 관련 종료 흐름 교정
R10은 원작 확인 함수의 성공 반환을 막고, 취소 그룹 디스패처를 호출한 뒤 종료 중 상태로 묶었습니다.
확인한 원작 디스패처는 버튼이 없거나 비활성이면 아무 동작 없이 반환하며, 종료 함수도 전환 중이면 거절합니다.
그러나 R10은 이 거절을 확인하지 않았습니다. 종료 신호가 실제 발생하지 않아도 후속 화면 처리를 막을 수 있습니다.
R11은 이 우회 경로를 삭제하고 원작 정상 성공 반환과 상태 큐 종료를 사용합니다.
성공 표시 MAIN+0x180=1을 유지합니다. 원작 페이드 완료 콜백이 추가 종료를 만들지 않게 하며,
논공 상태에만 적용하는 중복 종료 방어를 추가했습니다. 전역 턴 진행 함수를 막는 패치가 아닙니다.
취소가 실제 전달됐는지도 별도로 확인해, 단순 디스패처 호출을 취소 성공으로 간주하지 않습니다.

[2] 군주 유비 후보 누락
R10의 수정은 패치 자체의 자격/표시 계층에 머물렀습니다. 실제 후보 수집과 원작 확정은 공통으로
1eed10을 호출하며 이 함수는 군주를 거부했습니다. 원작 예정 랭크 3fae0 및 현재 랭크 3fa90도 별도로 거부했습니다.
R11은 세 원작 함수 입구를 검증 후 연결합니다. 군주/기록된 전 군주에게만 중진과 총 3회 자격을 적용합니다.
중진은 실제 랭크 자료에서 보상 3개가 열리는 단계로 계산합니다. 일반 무장의 공로 조건은 유지합니다.
현재 랭크 표시, 보상 선택 상태, 합계 제한, 원작 비용 및 확정 처리를 함께 맞췄습니다.

[3] 소속/신분 변경 후 저장정보 오판과 중복 지급 방어
기존 20바이트 Profile의 미사용 영역에 윗줄/아랫줄 사용 횟수, 최고 랭크와 유효 표시를 저장합니다.
기존 군주 이력 비트는 유지합니다. 네이티브 값이 내려가거나 양쪽 횟수가 뒤바뀐 경우 이미 저장된 합계를 복원합니다.
원작 값의 정당한 증가만 누적하고 합계 3 초과, 비정상 랭크/플래그는 거절합니다.
저장 직전 원작 직렬화보다 먼저 정합성을 회복하고 같은 상태로 보조 기록을 작성합니다.
기존 v3 포맷 크기·원본 해시·계정/슬롯 결합·저장 저널·개성/리롤/꽝 상태 검사를 제거하지 않았습니다.
모든 무장 ID에 공통 적용합니다. 유비/마등만 이름으로 예외 처리하는 코드가 아닙니다.
R9/R10에서 이미 사라져 검증할 수 없는 과거 내정 횟수는 임의로 만들어내지 않습니다.

[4] AI 선택/지급 분리
후보 방문 hook_ai_visit에서 ai_process 호출을 제거했습니다. 조회만으로 미지급 윗줄 추첨이 발생하지 않습니다.
실제 AI 확정 경로에서만 보상 선택/추첨을 진행하며, 직접 논공 화면이 활성인 동안 AI 확정을 막습니다.
처음 비어 있는 개성칸에 맞춰 새로운 윗줄 선택을 제한하고 나머지는 내정으로 보냅니다.
개성/꽝 확정 이후 실제 점유를 매번 다시 확인합니다. 가득 찼으면 교체나 추첨을 하지 않습니다.
이미 얻은 내정 보상과 일반 무장의 원래 선택 총량은 보존합니다.
원작 확정 결과 검증에 아랫줄 횟수도 포함하고, RNG 실패 시 임시 AI 선택 변경을 복구합니다.

[5] 내부 통지, 기존 기능 및 설치
행 갱신·선택 재표시·화면 등록 내부 통지는 보상 선택으로 받지 않습니다. 정상 네이티브 선택 입력은 유지합니다.
DLC/콜라보 후보 자료와 가챠 엔진은 R10 그대로이며 확률·혈연 보정·리롤 총량을 새로 조정하지 않았습니다.
개성 9칸/마우스 설명/프리셋 표시 연동의 기존 공유 DLL은 바이트 그대로 유지했습니다.
R9와 첨부 R10의 4개 변경 대상 파일 해시를 설치기 업그레이드 허용 목록에 추가했습니다.
독립 설치용 8개 payload 파일, 자동 관리 파일 백업, 롤백·제거·진단 도구를 포함합니다.
새 후크는 4곳, 전체 39곳입니다. 지원 빌드의 실제 함수 전체 해시와 후크 위치를 먼저 검증합니다.

소스 수정, Win64 DLL 빌드, 원본 명령어를 실행하는 경계 시험, 기존 회귀 및 설치 패키지 정적 검사를 수행했습니다.
현재 사용자 환경의 실게임 마등 멈춤 재현/해소와 유비 목록 실제 화면은 아직 직접 확인하지 못했습니다.
요청서의 장기 저장, 정상 턴 진행, 컨트롤러·빠른 입력 및 모든 모드 조합은 실게임 확인 대상으로 남습니다.
