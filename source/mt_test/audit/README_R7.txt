현재 검사 gate는 r7_suite_run.json 입니다.
r6_tests.json = R7 DLL에서 다시 실행한 원작 선택/기존 UI 회귀.
r7_tests.json = 최신 로그 seed 재현, 독립 확인창 구조/입력/실패/수명, 무장선택.
r7_compat_tests.json = 변경하지 않은 엔진/저장/DB/호환 계약.
cp03_stack_tests.json = Win64 stack probe 실제 기계코드.
r7_package_tests.json = 재빌드/PE/payload/정적 설치기/이전 정확한 해시 인식.
원작 UI/GPU/OS/비용 접점은 대체되었습니다. 실게임 무튕김 인증이 아닙니다.
과거 r2~r6 보고서는 이 결과에 중복 합산하지 마세요.
