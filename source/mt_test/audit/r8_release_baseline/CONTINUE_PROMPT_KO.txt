확인된 잘못된 가정
- layout+0x1c8은 단일 뒤로 버튼이 아니라 원작 하단 버튼 묶음.
- 0x6be850은 공용 end-event/fade 함수. 모든 코드를 Back으로 처리하면 안 됨.
- R7 검사는 하단 결정 클릭을 생략하고 state1을 직접 써서 문제를 놓쳤음.
- R7 실제 DLL에서 두 오류를 재현하고 R8 DLL에서 차단함.

변경
source/runtime_flow.inc: 명령 구분, 예 입력 해제 후 처리, 종료 콜백/중복 해제 가드.
source/native_controls.inc: 하단 묶음 좌표 처리 제거, 실제 모달 버튼 hit만 동의.
source/native_notice.inc: 원작 버튼을 부모 없는 별도 root로, 모두 layer6, 창과 함께 절대 좌표.
원작 등록 hook 1개 추가: H_UI_ENTER, vtable0x1447cc8 -> 0x6b4f20. 전체35 hooks.
전용 DLL과 전용 Resolver를 반드시 함께 설치. 공통4개 DLL 보존.

사용자 최종 규칙
윗줄 지휘병사만 개성 해금으로 변경. 원작 내정/랭크/두 줄 합계최대3/각 줄왼쪽우선 유지.
조운 내정2 -> 위첫칸 또는 내정셋째 한 개만 가능.
가챠 결과는 원작 선택색/선택표에 등록. 단계·무장별 선택 상태 독립.
결정만 최종 적용. 기존 개성 실제 교체는 무장·기존·신규 예/아니오 동의.
뒤로/ESC 예: 미확정 결과와 임시 선택만 폐기, 소모 리롤권은 유지, 보상/비용 반영 없음.
아니오: 그대로 복귀. 상단 확정/나감 없음.
계산 근거 글씨/정렬, 재추첨 높이/글꼴, 기존Hover 연동 유지.
능력치 비교는 대상/비교자 모두 원본DB. 실제 편집/성장 능력치 변경 금지.
황금 확률 상향/리롤 추가 논의는 미반영. 무장별 총5회 유지.

검증 범위

원작 보상 클릭/tick/공용 종료 바이트 + 실제 Win64 DLL 실행.
외부 OS/위젯/GPU/비용/fade 완료 접점은 대체. 실제 Windows 게임이 아님.
원시/독려 seed 재현, 잘못된 취소 경로, 빈공간/키홀드/늦은 콜백/중복 해제 검사.
