# SAN14CE R15 개성 성별·상충 제한 점검

2026-09-22. 이번 작업은 점검과 목록 작성이며, 배포 패치·게임 파일·세이브를 수정하지 않았다.

## 결론

- 남성 무장에게 경국을 포함한 여성 선택 대상 개성이 추첨될 수 있다. R15 가챠 대상 구조체와 읽기 함수에 성별이 없다.
- 게임 편집 판정의 고정 개성 배타그룹 및 효과 배타그룹과 비교해, 가챠에 필요한 차단 139방향(서로 다른 개성 조합 95쌍)의 누락을 확인했다. 숫자는 이번에 확정한 두 종류의 규칙만 포함하며 전체 제한 수가 아니다.
- 139방향 모두 실제 R15 컴파일 코드에서 후보 가중치가 양수이고, 해당 결과를 대기 상태에 놓은 확정 검사도 통과했다.
- OS와 게임 경계를 대체한 Linux 테스트에서 R15 Win64 코드를 실행했다. Windows 게임 내 화면·전투 발동 시험은 하지 않았다.

## 공식 자료와 판정 근거

코에이 공식 CE 한국어 웹매뉴얼: https://www.gamecity.ne.jp/manual/sangokushi14-pk/ce/kor/5300.html

공식 웹매뉴얼에는 개성이 항상 또는 조건 충족 시 발동한다는 설명이 있다. 확인한 공식 웹페이지에는 성별 제한과 비활성화 조합의 전체 표가 없어, 세부 목록은 확보된 CE 실행 파일의 개성 편집 판정과 원본에서 추출된 개성 DB를 대조했다. 아래 목록을 공식 웹페이지에 게시된 표라고 인용하면 안 된다.

분석 실행 파일은 기존 패치 작업에 사용한 game_runtime.exe이다. 일부 UI 패치가 포함된 확보본이며, 순정 전체 실행 파일과의 바이트 동일성을 주장하지 않는다.

- 실행 파일 SHA-256: `77ff1277fc042865ea0dd32137a63fb66742416dca465ab66776518ab11c4fb6`
- 개성 DB 출처 기록: base 0010_KO / scedaexce01.s14 + fixdataexce.s14, 활성·숨김 포함 219개.
- 성별 후보 제한: RVA 0x2158F0, 조건 코드 21/22와 편집 무장 성별 필드 +0x4A를 검사한다. 보조 성별 배제 판정 RVA 0x216F30.
- 개성 조합 제한: RVA 0x216060. 고정 ID 그룹, 동일 발동조건의 효과 배타그룹, 추가 반대 효과 및 사용자 개성 판정이 있다.
- 효과 배타그룹 구성: RVA 0x215D50. 이 경로에서는 추가 사용자 개성 그룹 옵션이 0이다.
- 패치 측: source/gacha.h의 GTarget, source/merit_runtime.c의 target_read, source/gacha.c의 g_distribution 및 g_accept, source/catalog.h의 blocked_pairs(105방향).

## 추가 검증 항목: 반대 효과와 사용자 개성

원작 판정 RVA 0x216AEC 이후에는 특정 무장 연결 여부, 발동조건, 조건값의 특수값 여부, 동일 효과 코드, 효과량 부호를 함께 검사하는 별도 분기가 있다. R15에는 이에 대응하는 일반 판정이 없다. 아래 11쌍은 DB의 발동조건·효과·부호가 이 분기와 맞는 후보이나, 개성 객체의 무장 연결 필드 +0xA2까지 확인되지 않아 위 확정 95쌍/139방향에는 포함하지 않았다. 최종 수정표로 사용하기 전에 해당 런타임 필드 또는 게임 편집 화면으로 확인해야 한다.

## 다음 패치에 반영할 범위

1. 대상 무장의 현재 성별을 읽고 여성 제한 개성을 남성 후보에서 제외한다. 원본 무장명 목록에 의존하지 않는다.
2. 원작에서 확인한 배타 관계를 추첨 순서와 관계없이 적용한다. 기존 상위·하위 개성 중복 방지 정책과 원작의 금지 조합은 구분한다.
3. 일반 추첨·재추첨·결과 확정에서 같은 유효성 검사를 사용한다. 미리보기 편집, 보류 결과와 실제 보유 개성도 함께 검증한다.
4. 기존 시나리오나 세이브의 개성을 임의 삭제하지 않고 신규 획득 제한을 먼저 고친다. 원작의 초기 배치와 편집 허용 조합이 다를 수 있다.
5. 적용 대상은 윗줄 개성 가챠 3칸이다. 아랫줄 내정에 재추첨권을 적용하지 않는다. AI의 재추첨권을 없애는 변경은 하지 않는다.
6. 성별이 캐시 키에 반영되고 편집 후 후보 캐시가 갱신되는지도 수정 시 검증한다.
