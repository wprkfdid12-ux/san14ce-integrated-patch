# 교훈·점검 폴더 — 먼저 읽기

삼국지14 CE 통합패치를 고치는 사람(기억이 지워진 다음 대화의 Claude 포함)이 **작업을 시작하기 전에** 읽는 폴더다.
이 폴더는 기록장이 아니라 **관문**이다. 여기 점검을 통과하지 못하면 판을 내지 못한다(사용자 2026-11-10).

## 지금 바로 할 것(새 대화에서)
1. 이 파일 → `01_작업규칙.md` → `06_기준값.md` 를 읽는다(짧다).
2. `python3 교훈_점검/관문.py --빨리` 를 돌려 지금 상태를 본다. 빨간 줄이 "지금 남은 일"이다.
3. `04_제보장부.tsv` 에서 상태가 대기·확인중인 줄, `05_소스장부.tsv` 에서 '바이너리' 줄을 본다.
4. 하려는 일에 맞는 점검표(`점검표/`)를 읽고 시작한다.
5. 작업 폴더 상세 기록은 `STATUS_R43.md`(작업 폴더 맨 위). 길어서 필요한 부분만 찾는다.

## 관문이 막는 것
- 교훈에 점검이 안 묶여 있다(c01)
- 통합편의 해시를 모듈이 따로 들고 있다 / 지금 통합편의를 모른다(c02)
- 우리 모듈이 통합편의 확인 구간을 먼저 고친다 — 순서 경쟁(c03)
- 소스 없는 DLL 이 늘었다 / 꾸러미 DLL 이 지금 소스의 빌드 결과와 다르다(c04)
- 게임 판 값이 소스마다 다르다 / 옛 판 값이 남았다(c05)
- 바뀐 파일에 수정 내역이 없다(c06)
- 제보 장부에 안 닫힌 것이 있다(c07)
- 화면 글자에 옛 판 이름이 있다(c08)
- 기색·계절 자리가 통합패치·통합편의 확인 구간과 만나는데 확인 기록이 없다(c11)
- 호환판에서도 켜진 AI 모드 자리가 통합·통합편의·기색·계절 자리와 겹친다 / 늦게 거는 AI 자리가 고치는 자리와 겹친다(c14)
- 게임 기록의 판 글자로 판을 구분하는 도구가 있다(c10)
- 오프라인 전체 시험(`test/run_offline_all.sh`)이 하나라도 실패한다

포장 도구(`make_cum_overlay.py`)는 관문 도장이 없으면 묶지 않는다.

## 버그 하나를 고칠 때의 고리
1. 제보 장부에 줄(대기) → 2. 원인을 코드로 확정 → 3. **고치기 전 코드로 실패하는 시험**을 만든다 → 4. 고친다 → 5. 시험을 `run_offline_all.sh` 에 넣는다
→ 6. 교훈 목록에 한 줄(점검 칸 = 그 시험) → 7. 수정 내역에 한 줄 → 8. 제보 장부를 '고침'으로 → 9. 관문.

같은 실수가 두 번 나오면 이 고리 중 하나를 빠뜨린 것이다.
