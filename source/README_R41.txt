■ 설치 방법 (딸깍)
1. 받은 ZIP 여러 개(1of N ~ N of N)를 전부 "같은 새 폴더"에 풉니다. (게임 폴더 안에 풀지 마세요)
2. 게임과 런처를 끕니다.
3. 그 폴더의 「설치.cmd」를 더블클릭합니다. 설치 창이 뜹니다.
   - 게임 폴더는 Steam 설치 위치에서 자동으로 찾습니다. 못 찾으면 [게임 찾기]로 SAN14CE_KO.exe 를 선택.
   - 위쪽 탭: 전체 / 편의 / 밸런스·규칙 / 정보·UI / 그래픽·화면 / 무장·얼굴 / 사운드. 탭은 분류일 뿐 번호는 그대로입니다.
   - 체크 = 선택. [선택 설치] = 체크한 항목 설치·갱신, [선택 제거] = 체크한 항목 제거. "이 탭만" 줄과 "모든 탭" 줄이 따로 있습니다.
   - 항목을 누르면 오른쪽에 설명(무엇을 하나 / 켜면 이렇게 됩니다 / 게임 안에서 켜고 끄는 곳 / 주의)과
     「게임 적용 확인」(마지막 게임 실행 때 그 항목이 실제로 적용됐는지, 일부만 됐으면 무엇이 안 됐는지)이 나옵니다.
   - 같이 못 쓰는 조합(예: 13번 논공 가챠 + 2번 자동 논공, 11번 3D 조형 + 2D 모드)은 설치 전에 알림창으로 막고 고르게 합니다.
   - 이전 설치기(R20~R40, R40 AI 호환판)로 깐 상태도 그대로 읽어 들입니다.
4. 문제가 나면: 게임 안 오류창이나 설치기 오류창의 글자를 [복사]해서 그대로 알려 주세요. 기록은 게임 폴더 SAN14_기록\ 에 모입니다
   (설치기 [기록 폴더 열기]).
